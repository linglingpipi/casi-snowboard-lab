基础原理

中立姿态

Neutral Position

在保持稳定和平衡的同时，为屈伸、旋转和身体位置调整保留活动空间。

  • 稳定不等于静止，姿态应允许继续移动。
  • 脚踝、膝和髋保留自然屈曲，避免停在动作极限。
  • 判断重点是接下来还有多少调整空间。

学习状态：已理解

基础原理

质心

Centre of Mass

将身体质量等效为一个点，用来理解身体位置、平衡与移动的关系。

  • 质心不是固定在某个身体部位的点。
  • 身体姿态改变时，质心位置也会改变。
  • 居中不意味着质心始终停在雪板正上方。

学习状态：已理解

基础原理

支撑区域

Base of Support

观察身体获得支撑的区域，以及它与质心的关系，帮助理解平衡。

  • 支撑区域需要结合雪板和雪面的接触方式理解。
  • 平板滑行与使用工作刃时，支撑关系会变化。
  • 它与质心的关系是分析平衡的基础。

核心滑行技能 · 观察与分析 · 教学与表达

身体位置与平衡

Position & Balance

身体位置随任务变化；平衡是在变化中保持控制，并为下一步动作保留调整空间。

  • Position 描述当前身体组织，Balance 描述动态控制能力。
  • 从前后、横向、垂直和旋转四个方向观察身体位置。
  • 有效的位置应适合当前任务，并保留继续调整的空间。

学习状态：学习中

旋转控制

Pivot

通过协调身体旋转控制雪板朝向，按转弯任务调节转板幅度，并与立刃、压力配合。

  • Pivot 关注雪板绕垂直轴的旋转，转板量取决于当前任务。
  • 从下肢协调引导雪板，避免每次都依赖大幅上身旋转或单纯甩后脚。
  • 较平的板更易转向；转板与立刃、压力及动作时机需要配合。

立刃控制

Edging

通过管理 Edge Angle、Working Edge、Inclination 与 Angulation，让雪板在不同任务中建立合适的抓刃、支撑和转弯表现。

  • Edge Angle 是连续变量，必须根据 speed、terrain、turn radius、snow conditions 和 task 调整。
  • Inclination 是整体质量向 turn inside 移动，Angulation 是通过关节角度进一步管理 Edge Angle 与 Balance。
  • 高 Edge Angle 不自动等于高 Edge Grip；Edging 还必须与 Position、Pressure、Pivot 和 Timing 协同。

压力控制

Pressure

Pressure 是对 snowboard 与 snow 之间作用力的管理；Flexion、Extension、Loading、Unweighting 和 terrain absorption 都是在不同任务与时机下调节这些 forces 的方式。

  • Pressure 不等于单纯“往下踩”，而是对 snowboard 与 snow 之间 forces 的调节与管理。
  • Flexion 与 Extension 对 Pressure 的影响取决于 movement speed、timing、terrain 和当前 board state。
  • Reactive Pressure Management 用于吸收与控制已有 forces，Proactive Pressure Management 用于主动 create / release / redistribute pressure。

时机与协调

Timing & Coordination

Timing 决定动作何时开始、持续多久和做到多少；Coordination 决定多个 Riding Skills 如何按正确 sequence、overlap 与 rhythm 共同产生有效 board performance。

  • Timing 不只关注开始时机，还包括 movement 的 duration 与 amount。
  • Coordination 不是所有动作同时发生，而是按 task 需要组织 sequence、overlap 与 blend。
  • Position、Pivot、Edging、Pressure 只有在合适 Timing & Coordination 下，才能共同形成高质量 turn outcome。

转点与板头板尾位移

Centre Pivot Point

同时观察板头和板尾如何位移，识别是否主要靠后脚扫出板尾来完成转向。

  • 中心转点是一种观察板头、板尾共同参与旋转的理想化示意。
  • 若板头相对稳定而板尾大幅横移，可进一步检查后脚扫板。
  • 转点不要求几何上严格落在雪板正中心。

有效居中与保持可移动

Centred & Mobile

居中是对当前任务保持有效控制；可移动是仍有余量继续调整身体与雪板。

  • Centred 是功能性的有效位置，不是静止的几何中心。
  • Mobile 包括上下、前后、横向和旋转方向的调整余量。
  • 判断时同时看当前控制和下一步能否继续移动。

脚踝膝髋协调屈伸

Coordinated Flexion

让脚踝、膝和髋共同参与位置调整，避免把大部分动作集中在髋部并提前用完活动范围。

  • 协调屈伸不要求三个关节角度完全相同。
  • 单靠髋部大幅折叠，即使看起来很低，也可能限制下肢可移动性。
  • 判断重点是当前动作后还能否继续屈伸和调整。

身体位置的四个方向

Four Dimensions of Position

用前后、横向、垂直和旋转四个方向描述身体位置，再判断它是否适合当前滑行任务。

  • 前后观察 nose 与 tail 方向，不把居中误解为全程固定的双脚压力比例。
  • 横向和垂直位置会随立刃、屈伸及地形任务变化。
  • 旋转方向关注身体各部分与雪板之间的朝向关系。

下肢引导雪板转向

Lower-Body Steering

通过髋到脚的下肢链条协调引导雪板朝向，减少不必要的大幅上身带动。

  • 下肢引导强调髋、股骨、膝、踝、脚与雪板之间的协调。
  • 上身相对安静不等于完全冻结。
  • “用膝和脚引导”不表示用力扭膝关节。

雪板转向角

Steering Angle

比较雪板纵轴朝向与实际行进方向，理解搓雪转弯中的转板量以及刻滑中的差异。

  • 转向角描述板的朝向与行进方向之间的角度差。
  • 搓雪转弯通常有可观察的角度差和横向滑移。
  • 刻滑时板尾更接近沿板头轨迹通过，不能把所有转弯都解释为大量转板。

中等半径搓雪转弯

Medium Radius Sliding Turns

通过 round shape、progressive lower-body steering、controlled skid、progressive edging 与 consistent rhythm，建立稳定可控的中等半径 Sliding Turns。

  • Roundness 来自整个 turn 中持续、渐进的 direction change，而不是弯尾突然大幅 Pivot。
  • Controlled skid 需要 lower-body steering、progressive Edge Angle 与 Pressure Management 共同工作。
  • Medium Radius 是观察 symmetry、rhythm、turn shape 与五大 Riding Skills 综合质量的核心 manoeuvre。

搓雪小回转

Short Radius Sliding Turns

Short Radius 通过更高 quickness，把 round shape、lower-body steering、edge release、pressure control、symmetry 与 rhythm 压缩进更短的 turn duration，而不是通过 rear-foot kick 强行快速转板。

  • Quickness 是在更短时间内完成完整 movement sequence，同时保持 round shape、speed control 与 rhythm。
  • Short Radius 需要 centre-oriented lower-body steering，避免 rear-foot kick / tail sweep 成为主要转向策略。
  • 及时 release old edge、快速管理 pressure，并保持 centred & mobile，是在更陡 terrain 中维持 Short Radius 质量的关键。

搓雪转弯

Sliding Turns

Sliding Turn 通过 Position、Pivot、Edging、Pressure 与 Timing 的组合，让 snowboard 在转向同时保持可控 skid；它不是“错误 carving”，而是一种主动可选的 turn outcome。

  • Sliding Turn 中 snowboard 在改变方向的同时存在受控横向滑移，通常具有更明显的 steering / pivot 成分。
  • Sliding 不是低级错误；steeps、trees、bumps、speed control 等任务都可能需要可控 skid。
  • 高质量 Sliding Turn 仍依赖五大 Riding Skills 与合适 Turn Shape，而不是单纯后脚扫板。

观察与分析

转弯阶段

Turn Phases

用 Initiation、Execution、Completion 分析一个完整 turn，并观察五大 Riding Skills 在不同阶段何时开始、发展与释放。

  • Initiation、Execution、Completion 是分析 turn progression 的时间框架，不是固定等长的动作模板。
  • Linked turns 中一个 turn 的 Completion 会与下一 turn 的准备和 Initiation 连续衔接。
  • 五大 Riding Skills 会贯穿不同 phases，但不同 turn type 的 movement strategy 可以不同。

学习状态：学习中

观察与分析

转弯形状

Turn Shape

Turn Shape 是 snowboard path 的结果；Round / Open shape 与 fall line、speed control、turn size 和 movement timing 密切相关。

  • Turn Shape 描述 snowboard path 的形状，与 Turn Size / Radius 不是同一个概念。
  • 更完整地把 turn 带向 across the slope，可以利用 direction change 帮助管理 speed，而不是只依赖弯尾 braking。
  • Fall Line 是分析 turn 前半段与后半段、speed build 与 completion 的重要空间参照。

Sliding Turns

Sliding Turn 通过 Position、Pivot、Edging、Pressure 与 Timing 的组合，让 snowboard 在转向同时保持可控 skid；它不是“错误 carving”，而是一种主动可选的 turn outcome。

  • Sliding Turn 中 snowboard 在改变方向的同时存在受控横向滑移，通常具有更明显的 steering / pivot 成分。
  • Sliding 不是低级错误；steeps、trees、bumps、speed control 等任务都可能需要可控 skid。
  • 高质量 Sliding Turn 仍依赖五大 Riding Skills 与合适 Turn Shape，而不是单纯后脚扫板。
