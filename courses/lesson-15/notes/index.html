01 / Advanced Movement Analysis

高阶动作分析

先定义 task 与 snowboard outcome，再用 Advanced Competencies 作为分析 filter，追溯到 Riding Skills 与 body movement，并通过可验证的 tactic 重新观察结果。

查看知识速览 ↗

CASI Framing

Assessment — printed page 7

Level 3 rider 需要：

  • REFINE Centred & Mobile Position、Turning With the Lower Body、Balance Along the Working Edge
  • CONSOLIDATE Strength & Flow、Arc to Arc、Loading & Deflection、Steering Versatility

Medium task criteria：

  • Core Riding Competencies
  • fluid linked movements
  • smooth forward → switch transition
  • pressure throughout turn to achieve roundness

Short & Long criteria：

  • balance against turn forces
  • regulate pressure / maintain snow contact
  • slide or carve according to terrain / speed
  • lower-body-led turning effort
  • link momentum
  • control / redirect snowboard

Study Guide — printed page 8

CASI 要求用自己的话区分 skills (movement patterns) 与 competencies (outcomes)，并讨论 refined Core Competencies 如何发展为 Advanced Competencies。

Self-Assessment — printed page 9

CASI Study Guide / Development Plan 要求 rider：

  • identify patterns across tasks
  • locate patterns by terrain / turn type / movement
  • identify technical focus
  • identify difficult tasks / movements
  • define improvement actions
  • measure progress
  • use peer / mentor / video feedback

Advanced Competencies — printed page 10

CASI technical presentation 把 Advanced Competencies 作为：

  • outcomes of advanced riding skills
  • board-performance concepts
  • tangible analysis filters

并指出 competency deficiency 可以通过 skill-development tactics 处理。

以上支持本课“先看 outcome、再用 competency 过滤”的方向；下面的具体七步流程是课程模型。

Course Analysis Pipeline

TASK
↓
SNOWBOARD OUTCOME
↓
ADVANCED COMPETENCY FILTER
↓
RIDING SKILL
↓
BODY MOVEMENT
↓
TACTIC
↓
RE-OBSERVE

这不是 CASI 官方固定流程。

Step 1 — Define Task

先明确：

  • terrain
  • speed
  • turn type
  • direction
  • corridor
  • intended outcome

不同 task 下，相同 movement 可能合理也可能不合理。

Step 2 — Observe Board Outcome

先看 snowboard，而不是先看姿势：

  • path
  • track
  • turn shape
  • speed
  • rhythm
  • corridor
  • slide / carve / blend

Step 3 — Apply Competency Filters

观察：

  • Strength & Flow
  • Arc to Arc
  • Loading & Deflection
  • Steering Versatility

这些是 riding-quality filters，不是四个孤立招式。

Step 4 — Trace to Riding Skills

再回到：

  • Position & Balance
  • Pivot
  • Edging
  • Pressure
  • Timing & Coordination

并结合：

  • Centred & Mobile
  • lower-body turning
  • working-edge balance

Step 5 — Identify Movement Pattern

问：

  • what moved?
  • when?
  • how much?
  • how fast?
  • in which phase?

Step 6 — Choose a Primary Tactic

课程词：

Primary Limiter

指当前最限制 desired outcome 的主要因素。

这不是 CASI 官方术语，也不表示其他 skills 完全没有问题。

一次训练优先改变一个主要变量，以便建立更清晰 feedback。

Step 7 — Re-observe

改变 tactic 后：

  • outcome 是否改善？
  • pattern 是否改变？
  • 是否能在不同 task 重现改善？

Skills vs Competencies

CASI printed page 8 正式要求候选人解释 skills 与 competencies 的区别，但当前 Course Guide 没有在该页提供完整答案。

本课程工作理解：

Skills / movements

  • rider 如何动作

Competencies

  • movement blend 所表现出的 riding quality / outcome

保持为课程解释。

Observation vs Diagnosis

Observation

可直接看到：

Heel-side below the fall line repeatedly chatters.

Diagnosis Hypothesis

可能原因：

  • pressure timing
  • edge timing
  • rigidity
  • balance
  • snow / equipment

Tactic

选择一个变量去验证 / 改善。

不要从 observation 直接跳到唯一原因。

Cross-Task Pattern

CASI Self-Assessment 明确要求找 across-task patterns。

课程 evidence ladder：

Single Moment
= Clue

Repeated Pattern
= Better Evidence

Repeated Across Tasks
= Stronger Diagnostic Signal

这不是正式统计标准。

Same Underlying Issue, Different Outcome

示例 hypothesis：late old-edge release。

Medium

可能：

  • late shape
  • completion skid

Short

可能：

  • rear-foot kick
  • rhythm break
  • brake / restart

Large

可能：

  • late edge change
  • abrupt loading
  • chatter

因此 visible symptom 不应直接等于 root cause。

Medium Radius Application

Official Level 3 task（任务规格：印刷页 6；评估 criteria：印刷页 7）：

  • 6–10 m CW
  • medium-radius sliding turns
  • forward + switch
  • advanced groomed slopes
  • intermediate speed

课程分析重点：

  • refined Core Competencies
  • fluid linked movement
  • roundness
  • pressure distribution
  • switch transfer

Arc to Arc filter 可以看 linking / roundness，但不要强迫该 task 变成 pure carve。

Short Radius Application

Official Level 3 task：

  • 3–4 m CW
  • advanced performance
  • groomed advanced terrain

课程重点：

  • quick force / pressure regulation
  • lower-body steering
  • intentional slide / carve choice
  • rhythm
  • momentum linking
  • quick release

避免：

Kick → Brake → Reset。

Large Turn Application

参见 large-turns。

课程重点：

  • larger turn forces
  • strong + mobile body organization
  • arc linking
  • board loading / release
  • adaptive steering

Personal Observation

用户 Heel-side “折下去以后压不动”需要 cross-task 验证：

Medium Sliding

  • 是否也 early hip fold？
  • 是否也很早耗尽 ROM？

Short

  • steep terrain 是否 lock / back seat / late release？

Large

  • force build 时是否仍 strong + mobile？
  • early movement 是否已经做完？
  • 是否出现 late pressure / chatter / abrupt release？

如果只在 Large 出现，更可能和 force / speed / pressure / edge context 相关；如果多 task 重复出现，基础 movement-pattern hypothesis 更值得优先验证。

02 / Large Turns

大回转

CASI Level 3 mandatory manoeuvre；在 7–15 m corridor 与 groomed intermediate terrain 中展示 advanced-performance long-radius turns，并通过 force、pressure、lower-body steering、momentum linking 与 snowboard redirection维持高级表现。

查看知识速览 ↗

CASI Framing

Mandatory Manoeuvre — printed page 6

Current Level 3 Riding Module Course Guide：

  • Large Turns
  • 7–15 m CW
  • groomed terrain
  • series of long-radius turns
  • advanced performance level
  • groomed intermediate terrain

CW = Corridor Width。

Task Criteria — printed page 7

Short & Long Radius Turns 共用：

  • balances against turning forces to create pressure in board
  • regulates pressure / maintains snow contact through flexion + extension
  • adjusts movement to create sliding or carved turns as required by terrain / speed
  • lower-body movements lead turning effort across varied shapes / sizes
  • links momentum between turns
  • controls / redirects snowboard

Course Agenda — printed page 5

Day Two training session 标为：

Large Turns (carving)

这是 training agenda label。

不要把它误解成：

  • 所有 Large Turns 永远必须 pure carve
  • terrain / speed 变化时禁止 blend
  • assessment 只看 pencil-line track

因为 printed page 7 的 Short & Long criteria 明确保留 sliding / carved outcome 的 task adaptation。

Course Framing

Large Turns 是 Lesson 13 的 Performance Carving concepts 最自然的应用 task之一。

本站分析：

↓

不是官方固定 sequence。

Strength & Flow Application

随着 speed / radius / forces 增加，观察：

  • body 是否 strong + mobile
  • 是否 defensive / rigid
  • 是否 early collapse / fold
  • movement 是否 continuous
  • line planning 是否提前

Arc-to-Arc Application

观察：

  • new edge / grip timing
  • round trajectory
  • release
  • COM movement through edge change
  • momentum linking
  • 是否每弯 reset

具体 competency 来源见 arc-to-arc；本批已建立正式应用关系。

Loading & Deflection Application

观察：

  • pressure 是否随 turn forces develop
  • board 是否在有效 grip 下 load
  • rider 是否能 manage / release
  • 是否出现 stomp / pressure spike
  • rebound / next-turn linking 是否受控

不从单一视频外观推断真实 board bend 数值。

Steering Versatility Application

即便 agenda 写 Large Turns (carving)，page 7 仍要求按 terrain / speed 调整滑行结果。

因此 advanced rider 不能只会：

hold pure carve at any cost.

应保留：

  • line adjustment
  • speed management
  • controlled blend
  • redirect capability

Performance ≠ Maximum Edge

Large Turn advanced performance 不等于：

  • maximum Edge Angle
  • touch snow
  • hip drag
  • maximum rebound
  • maximum speed

课程关注：

  • roundness
  • control
  • force management
  • movement continuity
  • board performance
  • adaptability

Personal Observation

针对用户 Heel-side：

  • forces 增大后是否变 rigid？
  • 是否 early hip fold 后 mid / late turn 缺少 ROM？
  • working-edge balance 是否稳定？
  • pressure 是否 late spike？
  • old edge 是否 hold too long？
  • release 后能否连续进入 next arc？
  • chatter 是否随 speed / harder snow / rigidity / timing 变化？

全部未验证。

Training Progression

未来雪上安全 progression：

  1. clean + round intermediate carve
  2. maintain mobility as forces grow
  3. notice pressure build naturally
  4. link release into next turn
  5. gradually raise performance
  6. vary line / speed while preserving control

不要从低质量 clean carve 直接跳 maximum edge / speed。

Teaching English

Stay strong, but stay mobile.

Let the pressure build through the turn.

Link the momentum into the next turn.

Keep the turn round.

Regulate the pressure and maintain snow contact.

Let the lower body lead the turning effort.

学习路径

本站学习顺序：先复习 refining-carved-turns 的平衡、可移动性、释放与适应能力，再在 Large Turns 中逐步应用高阶表现。
