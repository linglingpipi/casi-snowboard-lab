01 / Developing Carving

提高刻滑

通过更清晰的 edge roll / set、progressive flexion、pressure management 与 round turn shaping，把 clean carve 发展成更可控、更有适应性的 carved turn。

查看知识速览 ↗

本篇为第 11 课的课后学习整理。以下技术模型、drills、tactics 与英文提示均为课程解释，尚未核对 CASI 官方 Guide 原文、版本及页码，不作为已确认的 CASI official framing。Personal Observation 是个人体验；所有 Heel-side 成因分析均为 hypothesis，待视频 / 雪上验证。英文 Observation Language 为示例句，不代表已观察到用户存在该问题。

核心解释

Developing Carving 是在 clean carved outcome 基础上，继续发展 rider 对 carved turn 的主动控制。

可以把课程问题从：

Can I carve?

升级成：

Can I control the carve?

需要开始同时管理：

Turn Entry
+
Edge Progression
+
Pressure Progression
+
Turn Shape
+
Release

Turn Shape vs Riding the Sidecut

Riding the Sidecut

建立 edge 后，snowboard 会根据：

  • geometry
  • Edge Angle
  • loading
  • speed

沿一个自然 arc 行进。

如果 rider 主要只是跟随这个 arc，可以把它理解为：

riding the sidecut。

Shaping the Turn

Developing Carving 开始要求 rider 通过：

  • Edge
  • Position
  • Pressure
  • Flexion
  • Timing

主动改变：

  • turn roundness
  • pressure development
  • speed management
  • arc completion

因此 clean carve 不只是：

edge it and wait。

Edge Roll and Edge Set

Edge Roll

Edge Roll 可以先理解为：

Old Edge
↓
Edge Angle decreases
↓
Board approaches flatter state
↓
New Edge Angle develops
↓
New Working Edge

重点：

continuous transition。

Edge Set

Set the Edge 可以先理解为：

new working edge 真正建立有效、稳定的 snow contact，并开始承担 turn / support task。

因此：

Roll ≠ Set

Roll 是 edge-to-edge transition。

Set 是 new edge 开始有效工作。

Turn Entry

Developing Carving 强调更清晰的 turn entry：

Release
↓
Roll
↓
Set New Edge
↓
Arc Begins Developing

但：

Early Set ≠ Early Maximum Edge。

edging 中已经建立 Progressive Edging，因此目标仍然是：

Earlier Engagement
+
Progressive Edge Build

而不是 transition 后立刻达到最大 Edge Angle。

Progressive Flexion

本课把 Flexion 更明确放入 carved turn progression。

目标不是：

变得更低。

而是：

movement 随 turn progression 与 forces 变化持续发展。

课程 mental model：

Turn Entry
small / available flexion

↓

Turn Develops
flexion develops

↓

Forces Increase
legs continue managing

↓

Completion
movement options remain

Flexion Is Not Pressure

pressure 已经建立：

Flexion 不自动等于 Pressure 增加。

在 carving 中 Flexion 可能用于：

  • maintain mobility
  • manage increasing forces
  • adjust COM / board relationship
  • support working-edge balance
  • preserve movement options
  • prepare release

因此分析时不能只问：

rider 有没有蹲？

还要问：

  • 什么时候 flex？
  • flex 多快？
  • flex 多少？
  • 当时 board / forces 在做什么？

Pressure and Loading

Pressure Progression

课程 mental model：

ENTRY
edge establishes
pressure relatively manageable

↓

EARLY ARC
edge + sidecut begin shaping

↓

MID ARC
pressure develops

↓

LATE ARC
forces may increase

↓

COMPLETION
manage + prepare release

目标不是在 entry 一次性主动“压满”。

Board Loading

Loading 描述：

snowboard 当前承受 forces / deformation 的状态。

Flexion 描述：

rider joints 的 movement。

因此：

Loading ≠ Flexion。

完全可能出现：

Board Loading ↑
+
Rider Flexing

因为 rider 可能正在通过 Flexion 管理已经增加的 forces。

本课不提供具体 board deformation / force / radius 数值模型。

Working-Edge Balance

Developing Carving 中，working-edge balance 需要同时考虑：

  • Edge Angle
  • Pressure
  • Position
  • COM relationship
  • Timing
  • Snow Conditions
  • Speed

因此：

high Edge Angle alone is not the goal。

centred-and-mobile 仍然重要。

当 forces 增加时，rider 需要：

stay mobile rather than become locked。

Dynamic Inclination and Angulation

edging 中已有：

  • Inclination
  • Angulation

本课开始把它们放入 turn progression。

Early Turn

  • move into new turn
  • establish new edge relationship

Mid Turn

  • forces develop
  • body angles continue adjusting

Late Turn

  • maintain working-edge balance
  • preserve mobility
  • prepare release

这不是固定动作处方。

重点是：

body angles should remain adaptable through the arc。

Shape Through the Edge

Sliding Turn 可以通过较明显 Pivot 改变 snowboard direction。

Clean carved turn 中，如果为了让 turn 更 round 而直接加入大量 Pivot，可能破坏 carve。

因此 carved turn shaping 更依赖：

Edge Timing
+
Edge Angle
+
Pressure
+
Board Deformation
+
Speed
+
Position

去改变 arc。

本课把这个思路简称为：

Shape through the edge.

这是课程表达，不是 CASI 官方术语。

Break the Carve

Break the Carve 可以先理解为：

根据 terrain、speed、space、safety 或下一动作需要，主动结束 pure carved outcome。

例如：

Carved Arc
↓
Terrain / Speed Requires Adjustment
↓
Reduce Edge / Introduce Steering or Skid
↓
Manage Line

这不一定等于：

carving failure。

真实 riding 中 rider 应该具备：

  • carve
  • slide
  • blend

之间的主动选择能力。

Round Carved Turn and Speed Control

Clean track 不是唯一目标。

如果 carve 很 open：

More downhill travel
↓
Speed continues to build

Developing Carving 要开始真正管理：

  • roundness
  • completion
  • speed
  • line

因此目标变成：

clean + round + controlled。

Across the Turn

Initiation

Release
↓
Edge Roll
↓
New Edge Set

观察：

  • old edge 是否 release
  • roll 是否 smooth
  • new edge 是否及时 establish
  • 是否仍保持 centred & mobile

Execution

Edge develops
+
Flexion develops
+
Pressure develops
+
Arc is shaped

观察：

  • flexion 是否 progressive
  • body 是否仍 mobile
  • edge / pressure 是否同步
  • turn 是否越来越 round

Completion

Manage stronger forces
↓
Complete useful shape
↓
Decide whether to maintain or break carve
↓
Prepare release

重点不是：

顶住直到动作极限。

而是：

保持可选择性。

Chatter

Chatter 可以先理解为：

snowboard / working edge 在 snow 上快速重复跳动或震动，不能持续建立稳定 grip。

分析时检查：

Chatter
↓
Position
↓
Edge Timing
↓
Pressure
↓
Rigidity
↓
Snow / Equipment

不使用：

chatter = edge angle 不够

这种单变量解释。

如何观察或练习

观察 1：Roll vs Set

录像中区分：

  • board 什么时候开始换刃
  • new working edge 什么时候真正建立

避免把“已经 roll 过去”误认为“edge 已经有效 set”。

观察 2：Flexion Timeline

观察：

  • Flexion 从什么时候开始
  • 到 fall line 时已经用了多少
  • late turn 还有没有 movement options

观察 3：Turn Shape

即使 track clean，也检查：

  • turn 是否 open
  • roundness 是否够
  • speed 是否逐弯增加

观察 4：Pressure / Rigidity

如果 late turn 很重或 chatter：

  • rider 是否 locked
  • lower body 是否还能 flex / adjust
  • pressure 是否过于集中在 late turn

观察 5：Break the Carve

在安全、适当的 terrain 上，观察 rider 是否能：

  • maintain pure carve when desired
  • intentionally end / blend the carve when required

具体 drill 与 terrain progression 需官方资料和雪上教学进一步确认。

常见误区

误区 1：Clean track 就代表 carve 已经完成

不完整。

Developing Carving 还需要：

  • turn shape
  • pressure progression
  • speed control
  • release control

误区 2：Sidecut 会自动给我理想 turn shape

不对。

Sidecut 提供 arc potential，但 rider 仍需要管理 Edge、Pressure、Position 与 Timing。

误区 3：Flexion 就是“压板”

不对。

Flexion 可能用于管理 forces，而不是制造更多 pressure。

误区 4：越早蹲低越好

不对。

如果 turn entry 已经使用大量 Flexion / Angulation，mid / late turn 可能缺少 Remaining ROM。

误区 5：Pure carve 一定必须维持到最后

不对。

根据 terrain / speed / safety 主动 break carve 可以是 tactical choice。

误区 6：Higher Edge Angle 一定让 turn 更好

不对。

实际 outcome 还受到 Pressure、Position、Speed、Board、Snow、Timing 等影响。

助手解释

以下属于课程解释，不应视为 CASI 官方逐字原文：

  • “Can I carve?” → “Can I control the carve?”
  • “Early Set ≠ Early Maximum Edge.”
  • “Shape through the edge.”
  • “Training task: Can I keep it pure? Real riding: Should I keep it pure?”
  • “Flexion progression 太早，可能在 Pressure 真正发展时已经没有 ROM。”

Personal Observation

用户此前描述 Heel-side：

折下去以后，再继续压会感觉‘压不动’。

本课将待验证 hypothesis 进一步具体化：

Flexion Timing

  • 是否 turn entry 就大量 flex
  • 是否很早进入 low position

Angulation Timing

  • 是否为了 edge angle 太早做完大量 joint angles
  • 是否 mainly hip folding

Remaining ROM

  • 到 fall line 附近是否已接近 movement limit
  • mid / late turn pressure 增加时是否仍能继续 adjust

Pressure Development

  • pressure 是否随 arc 自然 build
  • 是否过早通过 large movement 主动“加压”

Edge Roll / Set

  • roll 是否已发生，但 set 是否较晚
  • old edge 是否 hold too long

Turn Shape

  • clean track 是否仍过于 open
  • speed 是否持续 build

Chatter

  • 是否与 speed / hard snow / rigidity / late pressure 明显相关

以上全部未通过视频或雪上验证。

Teaching English

Simple Explanation

Developing carving means controlling how the edge, pressure and body movements build through the whole turn.

Teaching Cues

Roll and set the edge early.

Let the edge build progressively.

Add flexion through the turn.

Stay mobile as the pressure builds.

Shape the turn instead of just riding the sidecut.

Keep some movement available for the bottom of the turn.

Break the carve if the terrain or speed requires it.

Observation Language

You're using most of your flexion very early.

The edge rolls over, but it doesn't really set until later.

The track is clean, but the turn is still quite open.

You're becoming rigid as the pressure builds.

Correction Language

Keep some flexion available for later in the turn.

Let the new edge establish earlier.

Shape the arc progressively instead of forcing it at the bottom.

Stay mobile while the board loads.
