01 / Mogul Line Choice

雪包线路选择

在非机压与雪包地形中提前读取地形、雪况、可用空间和下一段出口，选择能够兼顾控制、速度、转向机会与相对稳定走廊的线路，并与压力时机相协调。

查看知识速览 ↗

CASI Framing

基于当前项目已审计的 CASI Level 3 Riding Module Course Guide：

  • Printed p.6 / Free Run (Un-groomed Terrain)：要求在非机压、起伏地形展示 advanced-level control，选择 efficient line，保持 relatively consistent turn corridor。
  • Printed p.7 / Assessment Criteria：要求 effective lines、relatively consistent corridor，结合 terrain / snow 调整 body position 与 movements，并有 refined pressure regulation / steering。

Official PDF：https://members.casi-acms.com/documents/RidingModule_LEVEL%203%20COURSE%20GUIDE-EN.pdf

当前证据未定义唯一 Mogul Line、包顶换刃规则或最佳固定节奏。下述线路家族是本站课程分析模型。

Line and Timing Work Together

本课的关键不是单独把转弯动作做得更激烈，而是理解：

Terrain / Snow / Space
→ Line Choice
→ Where and how the board meets features
→ Loading / contact / steering opportunities
→ Pressure / Steering Timing
→ Board Outcome and next-line options

这是 qualitative decision model，非 CASI 固定算法或物理公式。Line 与动作相互影响，不能宣称路线单独决定所有压力结果。

Course Line Families

Round / Around

绕过一些凸起，利用较完整弧线或横坡运动安排速度控制。

可能的优势：在适宜坡度、雪况及空间下，为渐进 steering / pressure regulation 保留更多时间；适合初期的 line planning。

局限：需要足够侧向空间；硬雪包肩/人流/狭窄走廊可能使“绕包”并不容易。不是所有地形的最安全线路。

Crest / Shoulder-Oriented

利用某些雪包的肩部 / 顶部附近组织 release 与 direction change。结合后续的腿部活动和 unloading，可能获得更易 redirect 的机会。

局限：高点未必低压；雪包可能不规则、顶部硬或伴随失去 snow contact 的风险。不是每一弯都必须 crest edge change。

More Direct / Trough-Oriented

较多沿 fall line 或包槽走向滑行。在坡度与雪况相近时，可能加快速度累积、增加地形冲击，缩短可用于调整的时间。

局限：Direct 不是 advanced 的同义词；如果出现 panic brake / corridor loss 就与 Free Run desired outcome 不符。

真实路线可自由混合，不要求完整 run 固定某一种“线路风格”。

Shape, Speed and Corridor

与 turn-shape 的关系：

  • More round / completed path 在某些坡度和条件下可帮助分配方向变化与速度管理任务。
  • More open / direct path 在其他条件相近时可能容许更快 downhill travel，随后提高 steering / control demand。
  • Corridor 是 rider 路径组织与 line-planning quality 的 outcome，不等于每一个 turn radius 必须数学一致，也不是每一个 bump 必须配一弯。

课程总结：Speed management starts with line choice。这不是 CASI 逐字表述。

Anticipation and Strength & Flow

与 strength-and-flow 的联系：

  • 观察 upcoming features，而不只盯住当前 bump。
  • 提前规划 2–3 个 feature 的方向与 exit。
  • 保持 body organized and mobile，避免每个包后完全 reset。

Near / Next / Exit 是课程视觉扫描框架，不是固定官方观察距离。

Steering Versatility Application

steering-versatility 不要求每个 terrain 都做 high-edge carve。

Line、space、speed 和雪况变化时，滑手可以调整：

  • Controlled sliding / blend / carve 的 intended outcome；
  • Turn shape 和 size；
  • Pivot / Edge / Pressure 的组合。

Accidental skid 不自动代表 intentional blend；也不要因为路线看似直接就把高风险技法当成高水平。

Movement Analysis

使用 advanced-movement-analysis 的 Outcome First 逻辑：

Task / Terrain / Snow
→ Intended Line & Target Speed
→ Observed Corridor / Speed / Board Path
→ Contact / Pressure / Steering clues
→ Movement hypotheses
→ One-variable tactic and re-observation

例如看到 rider 每包后突然横板：先记录 turn shape、进入路线与速度变化，再考虑晚减载、过直 line、缺乏 ROM、trailing-foot kick 等竞争性假设，不立即锁定单一原因。

Training Ideas — Course Designed

Two Lines, Same Terrain

在可控小雪包、同一雪况 / 类似起始速度下比较较圆与包肩思路；记录 corridor、speed、pressure sensation、steering effort、continuity。避免多人场地中刻意占据多条横向路线。

Line First

先口头说出 upcoming two turns / features 的预期 line，再滑行，最后对比 plan 与 observed outcome。

Three-Feature Linking

在简单 terrain 提前看到下一两个 feature，避免每次只为通过眼前雪包而改向。

这些练习不是 CASI 的 Mandatory Free Run Progression。

Teaching English

Plan your line two bumps ahead.

Choose a line that gives you time to steer.

Look beyond the next bump to your exit.

Manage your speed with the line and turn shape.

02 / Mogul Pressure Timing

雪包压力与转向时机

理解不同地形位置与线路如何影响压力、板雪接触和释放/转向机会，在适当的时机调节加载、减载、改向、重新建立支撑，并把动作连到后续雪包。

查看知识速览 ↗

CASI Framing

项目最近一次实体审计的 CASI Level 3 Riding Module Course Guide printed p.7，关于 Un-groomed Terrain / Moguls Free Run 的 assessment criteria 包含：

  • Regulate pressure / maintain snow contact through flexion and extension；
  • Effective lines / relatively consistent turn corridor；
  • Adapt body position and movements to terrain / snow / features；
  • Refined pressure control and steering。

Official Riding PDF：https://members.casi-acms.com/documents/RidingModule_LEVEL%203%20COURSE%20GUIDE-EN.pdf

Supplementary teaching example（已独立核实）：CASI Level 3 Teaching Module Course Guide printed p.13 SAMPLE LESSON #1 — Freeride flow，printed p.21 Technical Presentation: Advanced Skill Development — Teaching Focussed。

Teaching PDF：https://members.casi-acms.com/documents/TeachingModule_LEVEL%203%20COURSE%20GUIDE-EN.pdf

这些教学示例不意味着所有 Level 3 Mogul Free Run 都必须使用固定 Down-Unweighting progression。

Line and Timing Work Together

mogul-line-choice 决定某一线路更可能怎样接触地形，从而改变 steering / pressure 的 timing demands。

Read feature & choose line
→ encounter terrain input / loading changes
→ regulate or release loading as needed
→ edge / steer / redirect
→ extend / re-establish support as appropriate
→ prepare next feature

动作可 overlap，不能把这条课程链理解成精确物理时程或 CASI 官方 choreography。

Pressure Management Intentions

Regulate — 调节

对 turn force / terrain interaction 引起的压力变化做可控调节。遇 rising terrain 时，腿可 flex / retract 以管理板雪压力与身体相对运动。

Release — 减载

在需要释放 working edge 或改变 snowboard direction 时，主动减少部分 loading，以利于 steer / change edge。减载不等于完全失去所有 snow contact，也不表示总压力为零。

Re-establish support — 重新建立支撑

在后续地形通过合适的 leg extension / movement 找回有效支持与雪面接触。不是无论 terrain 如何都猛踩雪板。

三者是本站组织动作意图的词组，不是 CASI 逐字标准三阶段。

Terrain Position and Timing

课程示意：

Terrain positionPossible terrain inputPossible tactical / movement intent
Approach观察即将发生的起伏、当前 edge/loading保持 mobile、选 line、提前预判
Rising faceterrain 可能快速推动 board towards riderFlex / absorb、regulate loading
Crest / shoulder某些 line + unloading strategy 可能有 release opportunity适时 release / redirect（非固定）
Falling terrainboard 可能相对身体远离Extend as needed for contact/support
Next trough / compression可能进入新的加载环境再次 regulate / plan next steering

不应理解为： crest 必定最低压，trough 必定最大压，所有 bump 必须同位置换刃。

Steering Window

本站定义：在给定 terrain、speed、edge engagement 与 loading 组合下，snowboard 相对更容易有控制地 release / redirect 的机会区间。

不是 CASI 标准术语、固定角度或唯一地形位置。

  • 在 strongly loaded / firmly edged 条件下，突然大量 Pivot 可能更困难。
  • Timing flexion / retraction + edge release 有时可以改善 redirect opportunity。
  • Crest / shoulder 可成为某些线路的机会点，但雪况、速度、接触及实际压力可能不同。

由“转不动”不能直接推定一定是 late release，还要检查 Line、Speed、Stance、Snow Conditions 和其他技巧。

Down-Unweighting and Terrain Absorption

Terrain Absorption：地形向上或起伏时，滑手借助 flexion / retraction 管理 terrain input，往往偏 reactive，但也可以预判。

Down-Unweighting：更主动安排的相对快速 flexion / retraction，试图释放 loading 并为 Edge Change / Board Redirect 创造机会。

Lesson 20 的 down-unweighting 已随本批同步；正式关系连接这一 specific tool 与雪包压力时机应用。

Teaching Module sample lesson 的表述是 specific technique—not a default riding style；不要把它当成 permanent crouch，也不要规定每一弯都做。

Reactive / Proactive

Lesson 20 Teaching Module 的 example-tactic context 有 Pressure skill components Reactive / Proactive。

  • Reactive：回应正在发生的 terrain loading，如 rising face absorption。
  • Proactive：根据下一地形预先安排 Pressure Release / Edge Change 的动作时机。

两者不是互斥标签；动作可能同时回应当前 feature 和为下一 feature 预备。

Mobility and Snow Contact

与 centred-and-mobile 联系：

  • Early low / rigid posture 可能耗尽 available flexion ROM；
  • Absorption 后需要 re-extension / future mobility；
  • Snow Contact 的目标是有效、可控的接触管理，不是保证每一帧 100% 持续贴雪；
  • Upper body 不必静止，通常希望 lower body 更能跟随地形变化。

“Legs as suspension” 仅是课程类比，非精确人体机械模型。

Terrain Rhythm and Turn Rhythm

与 timing-and-coordination 的关系：

  • Terrain Rhythm：feature / compression / relief 出现的时间分布；
  • Turn Rhythm：连续滑行的 initiation / shaping / completion 时间组织。

目标是让两个节奏相容：

Observe next 2–3 features
→ Plan continuous line
→ Movement through current bump
→ Keep options for the next
→ Re-read / update

并不等于一包一弯或固定每秒几次 retraction。

Failure Hypotheses — Course Only

Missed Steering Opportunity

Late terrain reading / release → board gets into a more loaded situation → large late steering / braking response。

Absorb Without Re-extension

Flex for first feature → remain compressed → next bump arrives → limited remaining ROM → instability。

Big Brake Per Bump

Too direct line / speed growth → hard sideways skid → next straight entry → repeated rhythm loss。

Reactive-only Vision

Only immediate feature is observed → no preparation for subsequent terrain → late movement options。

这些不是 CASI 官方 error taxonomy，也不能凭 single symptom 诊断唯一上游原因。

Training Development — Course Designed

  1. Groomed Pressure Timing：安全缓坡，探索 retraction / release，不追求猛踩、弹跳或 permanent low stance。
  2. Single Roller Pressure Map：低速、单个小起伏，比较 approach / rising / crest / falling 时 pressure 与 mobility 感受。
  3. Two Lines / Same Terrain：同地形、相近条件比较 Round 与 Shoulder 思路，记录 steering / contact / effort。
  4. Three-Feature Linking：在安全简易地形提前观察下一两个 feature，保留连续活动空间。
  5. Consistent Corridor：技术达到可控水平后再连续短段训练。

安全：避免初次直接进入陡峭或硬雪密集 moguls；优先现场教练与可控的开阔地形，无法控制速度或平衡时退出。

Movement Analysis

First observation：line / corridor、speed、contact、skid / redirect、first/next-feature rhythm。

Second interpretation：flexion / re-extension、edge release、steering source、pressure interaction、tactical choice。

Teaching English

Let the terrain help you release the board.

Retract your legs as you release the edge.

Extend to follow the terrain.

Don't force the turn when the board is heavily loaded.

Keep your movements flowing into the next bump.
