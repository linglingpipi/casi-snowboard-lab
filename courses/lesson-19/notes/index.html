01 / Terrain Adaptability

地形适应能力

在 terrain、snow、speed、space 与 features 变化时保持技术原则，同时调整身体位置、压力、转向与动作时机，使 snowboard outcome 继续有效。

查看知识速览 ↗

CASI Framing

Printed p3 supports varied / challenging terrain, precision / consistency / adaptability, steeps / bumps / variable snow. Printed p7 supports refined Core Competencies in varied advanced terrain and Un-groomed Free Run criteria: pressure regulation, snow contact, effective line, body-position / movement adaptation, refined pressure / steering. Printed p10 supports all-mountain application plus Strength & Flow line planning.

Course Definition

Terrain Adaptability = terrain / snow / speed / space / feature requirements 改变时，调整 movement 与 tactical choice，使 desired board outcome 继续有效。

它不是 CASI 四个 Advanced Competencies 之外的第五项 competency。

Principles Stable, Movements Adaptable

Stable Principles + Adaptive Movements = Terrain Adaptability

例如 centred & mobile principle 不变，但不同 terrain 的 body position、flexion / extension amplitude 可以不同。

Terrain Reading — Course Framework

Pitch / Surface / Features / Space / Exit 不是官方固定五项。

  • Pitch：speed build、timing window、corridor / shape demand
  • Surface：firm / soft / chopped / uneven / variable
  • Features：terrain 会改变 board-rider relationship
  • Space：影响 size / steering / speed / board performance
  • Exit：看 current feature 之外的 next turn / next line

Pressure Regulation

课程 qualitative model： Pressure Management = Turn Forces + Terrain Input + Rider Movement 不是物理公式。

Official support only covers pressure regulation, snow contact, flexion / extension and refined pressure control in bumpy terrain；未给固定 joint strategy / timing。

Terrain and Timing

Terrain feature 可改变 movement window。 本站加入 Feature Encounter 作为分析维度，不是官方 turn phase。

Anticipation

课程 model： Eyes Up → Read → Predict → Prepare → Execute CASI p10 只正式支持 looking ahead / planning lines。

Read → Plan → Ride → Update

本站 adaptability loop；不是官方 algorithm。

Personal Observation

用户 black Short Turns：

  • blue 较稳定
  • black 更困难

新增 hypothesis：

  • steeper pitch 是否缩短 timing window
  • line 是否过直
  • 是否 terrain change 后才 reaction
  • shape / corridor 是否与当前能力不匹配

Heel-side / Large：

  • snow / terrain input 是否改变 chatter / pressure feeling
  • forces 上升时是否仍 mobile

全部未验证。

Teaching English

Stay mobile and let the legs absorb the terrain. Look ahead to the next feature. Adjust your movements to the terrain. Keep the board in contact with the snow.

Source Boundary

Primary: CASI Level 3 Riding Module Course Guide, printed pp. 3, 7, 10. Course-only: Terrain Adaptability as a separate concept; terrain-reading five-part model; Near/Mid/Far; Feature Encounter; Read→Plan→Ride→Update; qualitative pressure equation.

  • Terrain change 前能否提前 adaptation？
  • Bumpy terrain 中 pressure regulation / snow contact 当前能力如何？
  • 哪些 principles 能真正 generalize 到 un-groomed terrain？

02 / Tactical Riding

战术滑行

先根据 terrain、space、speed 与 snow 选择 line、turn size、turn shape 和 slide/blend/carve outcome，再用 Position、Pivot、Edge、Pressure 与 Timing 去实现计划。

查看知识速览 ↗

CASI Framing

Printed p6 Free Run supports un-groomed / bumpy terrain, advanced control, efficient line and relatively consistent corridor. Printed p7 supports effective lines, body-position / movement adaptation, refined steering / pressure; Short & Long criteria support slide/carve according terrain/speed and varied shapes/sizes. Printed p9 contains TTPPEE in Self-Assessment / Exam Preparation. Printed p10 supports Strength & Flow line planning and Steering Versatility.

Technique vs Tactics — Course Definition

Technique = How do I control the snowboard? Tactics = What / where / when should I choose?

Tactical variables:

  • line
  • turn size
  • turn shape
  • slide / blend / carve
  • target speed

不是 CASI 当前页逐字定义。

Tactical Decision Model

Terrain → Read → Tactical Choice → Line / Size / Shape / Slide-Blend-Carve / Speed → Technique → Board Outcome → Update Course model only.

Effective Line

CASI officially uses efficient / effective line wording.

本站定义：

Effective Line = 让 rider 在当前 terrain 中以可控、连续、可调整方式完成 intended outcome 的路线。

不自动等于最快 / 最直 / 最陡。

Line and Speed

课程 model： More downhill/direct line → speed may build faster → later control demand may increase

课程总结：

Speed management starts with line choice.

不是 CASI 原句。

Turn Shape / Size

连接 turn-shape：

  • shape / size 是 tactical variables
  • 不建立固定 radius / speed 公式

Slide / Blend / Carve

连接 steering-versatility：

  • 根据 terrain / speed / space / intended outcome 主动选择
  • Advanced ≠ always carve
  • accidental skid ≠ intentional blend

Strength & Flow Application

连接 strength-and-flow：

  • look ahead
  • plan lines
  • blend skills
  • remain strong + agile

TTPPEE

Official p9：

  • Tactics
  • Technique
  • Physical
  • Psychological
  • Equipment
  • Environment

Official context = controllable exam-preparation elements / self-assessment.

本站扩展为 daily riding review checklist： Outcome not achieved → Tactics? Technique? Physical? Psychological? Equipment? Environment? 扩展用途不是 CASI fixed diagnostic system。

Tactical Context and Movement Analysis

连接 advanced-movement-analysis： Context / Terrain → Tactical Choice → Board Outcome → Technical Analysis 是课程扩展，不是 official diagnostic algorithm。

Personal Observation

Black Short Turns tactical hypotheses：

  • line too straight?
  • turns too open?
  • speed build too early?
  • corridor too ambitious?

课程 hypothesis： Steep + Direct/Open Line + Late Speed Management → Speed Builds → Timing Window Shrinks → Technique Degrades 未验证。

Heel-side / Large Turns 还应检查 tactical line、speed、snow、fatigue / ROM、equipment；Highback 仍非确认原因。

Training Ideas

  1. One Run, Three Outcomes
  2. Line First
  3. Shape Before Speed
  4. Tactical Commentary

Review Template

Terrain / Snow / Intended Line / Target Speed / Turn Strategy / Actual Outcome / Where Did I Adapt? / Where Was I Late?

Teaching English

Look ahead and plan your line. Choose a line that gives you time to move. Match the turn shape to the terrain. Manage your speed with the line, not just with braking. Look past the feature to your next turn.

Source Boundary

Primary: CASI Level 3 Riding Module Course Guide, printed pp. 6, 7, 9, 10. Course-only: Technique/Tactics definition; tactical decision chain; Effective Line course definition; line/speed mental model; daily-riding TTPPEE use; user tactical diagnosis.

  • Line planning 是否能减少 late braking？
