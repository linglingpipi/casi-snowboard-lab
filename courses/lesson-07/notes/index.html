01 / Turn Phases

转弯阶段

用 Initiation、Execution、Completion 分析一个完整 turn，并观察五大 Riding Skills 在不同阶段何时开始、发展与释放。

查看知识速览 ↗

本篇为第 7 课的课后学习整理，包含课程解释与待验证观察；尚未逐段核对 CASI 官方原文、版本及页码。

核心解释

Turn Phases 是用来分析一个完整 turn 如何发展的一套时间框架。

本课使用三个主要阶段：

  1. Initiation
  2. Execution
  3. Completion

Initiation

可以先理解为：

离开旧 turn，并开始建立新 turn。

常见分析内容包括：

  • old edge release
  • snowboard 变得 flatter
  • COM / body organization 朝 new turn 调整
  • 根据 turn type 开始 redirect board
  • pressure release / redistribution

Initiation 的重点不是简单“赶紧把板转过去”。

在不同 turn type 中，Pivot 的 amount 可以不同。

Execution

可以先理解为：

新 turn 被逐渐建立并发展的阶段。

常见分析内容包括：

  • body / COM 进入新的 turn relationship
  • new edge develops
  • steering / turn shape develops
  • pressure begins to build or be managed
  • rider balances through the arc

本课把它描述为“turn 真正长出来的阶段”，这是教学性比喻。

Completion

可以先理解为：

当前 turn 的 shape 被完成，同时 rider 开始准备下一 turn。

常见分析内容包括：

  • finish steering requirement
  • manage increasing / changing forces
  • manage or begin releasing edge
  • re-organize body position
  • prepare next transition

Completion 不等于：

movement 停止。

在 linked turns 中，上一 turn 的 completion 与下一 turn 的 initiation 会连续衔接。

Turn Phases Are an Analysis Tool

不要把三个 phases 理解成：

33% / 33% / 33%

不同的：

  • turn radius
  • terrain
  • speed
  • turn type
  • riding task

都会让 phase 的长度和边界发生变化。

因此 Turn Phases 是：

分析 progression 的工具，而不是机械时间表。

Five Riding Skills Across the Phases

可以用下面的问题分析一个 turn：

PhasePosition & BalancePivotEdgingPressureTiming & Coordination
Initiation身体如何离开旧 turn、进入新 turn？是否需要 redirect？old edge 如何 release / new edge 如何开始？pressure 如何 release / redistribute？movement sequence 是否合适？
Execution是否 centred & mobile？steering 如何发展？Edge Angle 如何建立？pressure 如何 build / manage？是否 progressive？
Completion是否为 next turn 保留空间？steering 是否完成 task？edge 是否准备 release？forces 是否被有效管理？是否顺畅进入下一 turn？

这是本课程的分析表，不是 CASI 固定处方。

如何观察或练习

观察 Snowboard Path

先不要看 rider 姿势。

先看：

  • 一个 turn 从哪里开始？
  • snowboard 什么时候改变 direction？
  • fall line 前后 path 是否连续？
  • turn completion 是否真正把 snowboard 带向计划的方向？

分阶段看视频

把一个 turn 暂停成：

  • Initiation
  • Execution
  • Completion

然后分别观察五大 Riding Skills。

Linked Turns

观察：

当前 turn 的 completion 是否已经自然进入下一 turn？

如果每一弯之间都出现明显停顿、braking 或重新准备，可能说明 flow / timing 仍需分析。

常见误区

误区 1：Initiation 就是快速扭板

Initiation 还包含：

  • release
  • body movement
  • edge transition
  • pressure redistribution

Pivot 只是可能参与的一个 Skill。

误区 2：Completion 就是“弯结束了”

Linked turns 中，Completion 同时承担 next-turn preparation。

误区 3：三个 phase 时间必须一样

没有这种固定比例规则。

误区 4：所有 turn 都用相同 phase strategy

Sliding、Carving、Short Turns、Terrain Riding 的 movement strategy 可以明显不同。

开放问题

  • Carved Turn 与 Sliding Turn 在 Initiation 中最大的 Skill 差异是什么？
  • Short Radius Turns 中三个 phases 会压缩到什么程度？
  • 我的黑道 short turns 问题主要发生在哪一个 phase？

02 / Turn Shape

转弯形状

Turn Shape 是 snowboard path 的结果；Round / Open shape 与 fall line、speed control、turn size 和 movement timing 密切相关。

查看知识速览 ↗

本篇为第 7 课的课后学习整理，包含课程解释与待验证观察；尚未逐段核对 CASI 官方原文、版本及页码。

核心解释

Turn Shape 描述的是：

snowboard 在雪面上走出的 path 形状。

它是 riding outcome，不是某一个 body movement。

Fall Line

Fall Line 可以先理解为：

坡面上最直接向下的方向。

当 snowboard 更接近 fall line 时，通常更容易出现 speed build 的趋势。

因此 Fall Line 是分析：

  • turn 前半段
  • turn 后半段
  • speed
  • completion

的重要参照。

Above the Fall Line

可以先理解为：

新 turn 建立后、snowboard 尚未完全通过 fall line 的前半段。

Below the Fall Line

可以先理解为：

snowboard 通过 fall line 后，继续向 across the slope 发展的后半段。

这些描述用于建立空间理解，不应机械地当成固定时间比例。

Round Turn

Round Turn 可以先理解为：

direction change 更 progressive，snowboard path 更连续地从一个方向发展到 across the slope。

常见结果可能包括：

  • speed control 更平顺
  • pressure development 更连续
  • linked turns 更容易保持 flow

Open Turn

Open Turn 可以先理解为：

path 更直接向 downhill，turn completion 相对更少横过坡面。

Open 并不自动等于错误。

是否合适取决于：

  • speed goal
  • terrain
  • corridor
  • turn task

Turn Shape vs Turn Size

Turn Shape 与 Turn Size 不一样。

Turn Size 更接近：

  • short
  • medium
  • large

Turn Shape 更接近：

  • round
  • open
  • progressive
  • abrupt / Z-like path

两个 turn 可以 size 接近，但 shape 完全不同。

Shape Develops Through the Turn

Turn Shape 不是在某一个瞬间“做出来”的。

它是 turn-phases 中 direction change 持续发展的结果。

因此 shape 会受到：

  • Pivot
  • Edging
  • Pressure
  • Timing & Coordination

共同影响。

Turn Shape and Speed Control

课程的关键理解：

Speed Control 不只等于 braking。

如果 turn 更完整地发展到 across the slope，snowboard 的 travel direction 会更多离开 fall line，从而可以通过路线本身管理 speed。

课程 mental model：

Turn Shape
↓
Direction Control
↓
Speed Control

这是教学框架，不是完整物理模型。

Z-Shaped Path

本课用 “Z-shaped” 作为观察比喻：

  • 前半段较直
  • snowboard 在 fall line 附近停留较久
  • completion 突然大幅 redirect / brake

它不作为已核实的 CASI 官方错误分类。

如何观察或练习

先看轨迹，不先看姿势

观察视频时先问：

  • turn 是 Round 还是 Open？
  • direction change 是 progressive 还是集中在弯尾？
  • snowboard 在 fall line 附近停留多久？
  • completion 是否真正完成 across the slope？

比较左右 Shape

比较 Heel-side 与 Toe-side：

  • size
  • duration
  • roundness
  • completion

如果一侧明显更开放，可能需要进一步检查五大 Skills。

用路线控制速度

在安全、适当的 terrain 中：

  • 不追求突然横板 brake
  • 尝试更连续地完成 turn shape
  • 观察 speed 是否通过 path 变得更可控

具体 drill 应由后续雪上课程根据 terrain 和 rider 状态设计。

常见误区

误区 1：Speed Control 就是把板横过来刹

Turn Shape 本身也可以参与 speed management。

误区 2：Round 越圆越高级

Roundness 必须服务于当前 task。

有些任务需要更 open line。

误区 3：Turn Radius 就等于 Turn Shape

Radius / size 与 shape 是两个不同维度。

误区 4：只通过身体姿势判断 turn quality

Turn Shape 是 snowboard path outcome，应先观察 board path。

  • CASI Level 2 Course Guide

当前课包没有保存具体版本、页码或原文。

  • QuickRide 关于 Shape / Size / Slope 与 Speed 的正式表述

  • Corridor Width 的当前官方标准

开放问题

  • 不同 radius 下，理想 Turn Shape 会如何改变？
  • Short Radius 中如何保持 roundness 而不变成大幅 braking？
  • Carving 中 “round” 的 path 与 sliding turn 有什么不同？
  • 我的黑道 short turns 是否出现典型 late-completion / Z-like path？
03 / Sliding Turns

搓雪转弯

Sliding Turn 通过 Position、Pivot、Edging、Pressure 与 Timing 的组合，让 snowboard 在转向同时保持可控 skid；它不是“错误 carving”，而是一种主动可选的 turn outcome。

查看知识速览 ↗

本篇为第 7 课的课后学习整理，包含课程解释与待验证观察；尚未逐段核对 CASI 官方原文、版本及页码。

核心解释

Sliding Turn 可以先理解为：

snowboard 在改变方向的同时，存在一定程度的受控横向滑移 / skid。

在 Sliding Turn 中：

  • board longitudinal axis 与 exact direction of travel 可以存在差异
  • Pivot / steering 通常比 pure carved turn 更明显
  • Edge Angle、Pressure 与 Position 仍然决定 skid 是否可控

因此 Sliding Turn 不是：

只靠后脚把 board 扫出去。

Sliding Is a Valid Outcome

Sliding 不应被理解成：

“Carving 失败了。”

它是一种主动可选择的 snowboard outcome。

很多场景可能需要更多 slide / skid：

  • steep terrain
  • trees
  • bumps
  • narrow corridor
  • tactical speed control
  • short-radius steering tasks

高级 rider 的目标不是永远 carve，而是拥有：

根据 task 选择 slide、carve 或两者之间不同 blend 的能力。

这属于本课的核心课程理解；具体 CASI 官方 wording 仍待来源核实。

How Sliding Turns Work

Sliding Turn 仍然是五大 Riding Skills 的共同结果。

Position & Balance

rider 需要保持 centred & mobile，才能继续 redirect board、调节 edge 与 pressure。

Pivot

pivot 通常承担更明显的 board redirection / steering。

但 Pivot amount 应与 task 匹配。

Edging

edging 决定：

  • old edge release
  • new edge engagement
  • skid / grip 的 balance
  • working-edge control

Pressure

pressure 影响：

  • board loading
  • edge support
  • turn development
  • terrain adaptation

Timing & Coordination

timing-and-coordination 决定：

  • 什么时候 release
  • 什么时候 redirect
  • 什么时候 build new edge
  • 什么时候 manage pressure

因此 Sliding Turn 不是一个单动作技术。

Sliding Turn Across the Phases

Initiation

课程分析框架：

Release old edge
↓
Board becomes easier to redirect
↓
Body moves toward new turn
↓
Begin steering as needed

Execution

Board continues redirecting
+
New edge develops
+
Pressure develops / is managed
+
Turn shape becomes clearer

Completion

Continue steering as needed
↓
Bring snowboard more across the slope
↓
Manage speed and forces
↓
Prepare release into next turn

这是学习框架，不是固定动作处方。

Turn Shape and Speed Control

Sliding Turn 的质量不能只看：

skid 有多少。

还要看：

  • Turn Shape 是否符合 task
  • speed 是否可控
  • movements 是否 progressive
  • skid 是否 predictable
  • linked turns 是否流畅

turn-shape 可以帮助 rider 用 path 管理 speed，而不是每一弯都依赖 abrupt braking。

Beginner / Novice Context

本课提到 QuickRide 中：

  • Beginner Turns 更关注 edge-to-edge turning 的建立
  • 后续 Flow 阶段会把 linked turns、flexion / extension、speed control 等进一步组合

但本课包没有保留 QuickRide 官方段落，因此这一部分仅保留为课程上下文，具体 wording 需核实。

如何观察或练习

观察 Board Orientation 与 Travel Direction

从俯视视频或轨迹观察：

  • board 是否发生 controlled skid
  • steering 是否 progressive
  • 是否 sudden rear-foot sweep
  • skid amount 是否与 task 匹配

观察 Turn Shape

先看：

  • Round / Open
  • completion
  • speed control
  • linked flow

再判断是哪一个 Riding Skill 导致 outcome。

观察是否只靠弯尾 Brake

典型待检查 pattern：

Open initiation
↓
Speed builds
↓
Late large pivot
↓
Abrupt skid / braking

如果出现，需要进一步分析：

  • timing
  • pivot
  • edging
  • position
  • pressure

而不是只说“搓雪太多”。

常见误区

误区 1：Sliding = 错误

不对。Sliding 可以是有意选择的 outcome。

误区 2：会 Carving 以后就不需要 Sliding

不对。不同 terrain 和 tactics 仍然需要 steering versatility。

误区 3：Sliding Turn 就是后脚扫板

高质量 Sliding Turn 需要五大 Riding Skills 协调。

误区 4：Skid 越少越好

Skid amount 应根据 task 调整，而不是一律最小化。

误区 5：只要能控速就是好 Sliding Turn

还要看：

  • turn shape
  • symmetry
  • timing
  • balance
  • predictability
  • flow

Personal Observation

用户目前：

  • 蓝道 short turns 基本稳定
  • 黑道 short turns 更困难

本课建议雪上观察：

  • 黑道是否出现 late large pivot
  • rear-foot sweeping 是否增加
  • skid 是否集中在 Completion
  • turn initiation 是否太 open
  • speed 是否通过 abrupt braking 控制
  • left / right turn shape 是否明显不对称

这些都没有经过视频或雪上验证。

Teaching English

Simple Explanation

A sliding turn changes direction while the snowboard is also skidding across the snow.

Teaching Cues

Let the board come around progressively.

Finish the turn more across the slope.

Keep the skid controlled.

Don't kick the back foot out.

Release the old edge smoothly.

Keep the turns round and consistent.

Observation Language

Most of the skid happens at the end of the turn.

You're pushing the tail out quite suddenly.

The turn is staying very open above the fall line.

Correction Language

Start shaping the turn earlier.

Let the board steer more progressively.

Finish the turn a little more across the slope.
