02核心解释

Turn Phases 是用来分析一个完整 turn 如何发展的一套时间框架。

本课使用三个主要阶段：

  1. Initiation
  2. Execution
  3. Completion

Initiation

可以先理解为：

离开旧 turn，并开始建立新 turn。

常见分析内容包括：

  • old edge release
  • snowboard 变得 flatter
  • COM / body organization 朝 new turn 调整
  • 根据 turn type 开始 redirect board
  • pressure release / redistribution

Initiation 的重点不是简单“赶紧把板转过去”。

在不同 turn type 中，Pivot 的 amount 可以不同。

Execution

可以先理解为：

新 turn 被逐渐建立并发展的阶段。

常见分析内容包括：

  • body / COM 进入新的 turn relationship
  • new edge develops
  • steering / turn shape develops
  • pressure begins to build or be managed
  • rider balances through the arc

本课把它描述为“turn 真正长出来的阶段”，这是教学性比喻。

Completion

可以先理解为：

当前 turn 的 shape 被完成，同时 rider 开始准备下一 turn。

常见分析内容包括：

  • finish steering requirement
  • manage increasing / changing forces
  • manage or begin releasing edge
  • re-organize body position
  • prepare next transition

Completion 不等于：

movement 停止。

在 linked turns 中，上一 turn 的 completion 与下一 turn 的 initiation 会连续衔接。

Turn Phases Are an Analysis Tool

不要把三个 phases 理解成：

33% / 33% / 33%

不同的：

  • turn radius
  • terrain
  • speed
  • turn type
  • riding task

都会让 phase 的长度和边界发生变化。

因此 Turn Phases 是：

分析 progression 的工具，而不是机械时间表。

Five Riding Skills Across the Phases

可以用下面的问题分析一个 turn：

PhasePosition & BalancePivotEdgingPressureTiming & Coordination
Initiation身体如何离开旧 turn、进入新 turn？是否需要 redirect？old edge 如何 release / new edge 如何开始？pressure 如何 release / redistribute？movement sequence 是否合适？

这是本课程的分析表，不是 CASI 固定处方。

03如何观察或练习

观察 Snowboard Path

先不要看 rider 姿势。

先看：

  • 一个 turn 从哪里开始？
  • snowboard 什么时候改变 direction？
  • fall line 前后 path 是否连续？
  • turn completion 是否真正把 snowboard 带向计划的方向？

分阶段看视频

把一个 turn 暂停成：

  • Initiation
  • Execution
  • Completion

然后分别观察五大 Riding Skills。

Linked Turns

观察：

当前 turn 的 completion 是否已经自然进入下一 turn？

如果每一弯之间都出现明显停顿、braking 或重新准备，可能说明 flow / timing 仍需分析。

04常见误区

误区 1：Initiation 就是快速扭板

Initiation 还包含：

  • release
  • body movement
  • edge transition
  • pressure redistribution

Pivot 只是可能参与的一个 Skill。

误区 2：Completion 就是“弯结束了”

Linked turns 中，Completion 同时承担 next-turn preparation。

误区 3：三个 phase 时间必须一样

没有这种固定比例规则。

误区 4：所有 turn 都用相同 phase strategy

Sliding、Carving、Short Turns、Terrain Riding 的 movement strategy 可以明显不同。
