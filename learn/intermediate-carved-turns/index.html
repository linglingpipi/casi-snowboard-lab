01导读

本篇为第 10 课的课后学习整理。以下技术模型、drills、tactics 与英文提示均为课程解释，尚未核对 CASI 官方 Guide 原文、版本及页码，不作为已确认的 CASI official framing。Personal Observation 是个人体验；所有 Heel-side 成因分析均为 hypothesis，待视频 / 雪上验证。英文 Observation Language 为示例句，不代表已观察到用户存在该问题。

02核心解释

Intermediate Carved Turns 是从 Sliding Turn 进入 clean carved outcome 的核心 manoeuvre。

本课当前学习目标不是追求：

  • maximum Edge Angle
  • touch snow
  • hip drag
  • racing-style performance

而是建立：

Clean Track
+
Round Shape
+
Early / Progressive Edge
+
Working-Edge Balance
+
Pressure Control
+
Consistency

Sliding vs Carved Outcome

steering-angle 已经建立：

  • Sliding Turn 中，snowboard longitudinal axis 与 exact direction of travel 可以存在明显角度差
  • Pure carved outcome 中，tail 更接近沿 nose 的 track 通过

因此本课把 clean carve 理解为：

snowboard 更主要沿 working edge 与 sidecut 所形成的 arc 行进，并明显减少不必要的 transverse skid。

这是课程解释，不作为 CASI 官方逐字定义。

Sidecut

Sidecut 是 snowboard 几何形状的一部分。

本课使用以下简化 mental model：

Edge Angle develops
↓
Working edge contacts snow
↓
Pressure / loading develops
↓
Board follows a curved arc

真实 snowboard deformation、雪面 interaction 与 turn radius 更复杂，本课不提供精确物理模型。

Remove Unnecessary Pivot

pivot 在不同 task 中使用量不同。

Sliding Turn 通常需要更明显 steering / Pivot。

Clean Carve 则需要减少不必要 Pivot。

需要重点避免：

Transition
↓
Pivot first
↓
Steering angle develops
↓
Then increase edge

这可能让 turn initiation 已经产生 skid。

Carving 更接近：

Release old edge
↓
Roll toward new edge
↓
Establish new working edge
↓
Let edge / sidecut begin shaping
↓
Pressure develops

Carving Sequence

本课的核心 sequence：

Release
↓
Roll
↓
Set / Establish New Edge
↓
Edge + Pressure Develop
↓
Board Follows Arc
↓
Round Completion
↓
Manage / Release

这不是机械动作处方，而是分析 clean carving movement order 的课程框架。

Early Edge Engagement

edging 已经记录：

Early Edge Engagement 是 transition 后较早建立 new working edge，而不是 turn 很晚才突然增加 Edge Angle。

本课把它放进 carving：

  • old edge release 后，新 edge 较早开始建立
  • new edge engagement 应 progressive
  • early 不等于 instantly maximum edge
  • above / below the fall line 可用于观察 edge timing

如果 new edge engagement 太晚：

Transition
↓
Board remains flatter
↓
Board travels closer to fall line
↓
Speed builds
↓
Late abrupt edge

可能带来：

  • late pressure
  • skid
  • heavy completion
  • less round turn shape

Across the Turn Phases

Initiation

课程分析框架：

Release old edge
↓
COM / body moves toward new turn
↓
Roll to new edge
↓
Establish working edge

重点观察：

  • 是否还带着 old edge
  • 是否先 Pivot 再 Edge
  • new edge 是否建立得过晚
  • body 是否 centred & mobile

Execution

Working edge established
↓
Edge Angle develops
↓
Pressure develops
↓
Board follows / develops arc

重点观察：

  • clean track 是否持续
  • body 是否能平衡在 working edge relationship 上
  • edge / pressure 是否 progressive
  • rider 是否还有 ROM

Completion

Round shape develops
↓
Increasing forces are managed
↓
Speed controlled through path
↓
Prepare release

Completion 不是把 edge / pressure 一直顶到极限。

需要为 next turn 保留 release 与 movement options。

Inclination and Angulation

edging 中已有：

  • Inclination：整体 mass 向 turn inside 移动
  • Angulation：通过 ankles / knees / hips 创建 joint angles

Carving 中两者会共同参与 working-edge balance。

课程重点：

Angulation 不等于单纯折腰。

Heel-side 如果：

  • ankle contribution 很少
  • knee contribution 很少
  • hip folding 很大

即使身体看起来更低，也不代表 Edge / Balance / Pressure 更有效。

Working-Edge Balance

Carving 不只是把 snowboard 放到高 Edge Angle。

更重要的是：

rider 能否在当前 working edge 上维持有效、可继续调节的 dynamic balance。

它涉及：

  • Edge Angle
  • Position
  • COM relationship
  • Pressure
  • Speed
  • Snow Conditions
  • Timing

因此：

High Edge Angle ≠ High Edge Grip

与 Lesson 04 的结论一致。

Pressure Progression

pressure 已经强调 Pressure 不等于单纯“往下踩”。

在 carving 中可使用：

Initiation
edge establishes / pressure reorganizes

Execution
pressure develops

Arc
board loads / deforms

Completion
increasing forces are managed

Transition
pressure / edge release

需要避免：

一入弯就通过 large flexion 或“猛踩”试图一次性制造全部 Pressure。

Board Deformation

本课把 board deformation 作为 carving performance 的基础概念：

Edge + Pressure
↓
Board Loads / Deforms
↓
Arc Behaviour Changes

这是课程 mental model。

不提供具体 bend amount、force number 或真实 turn-radius equation。

Chatter

Chatter 可以先理解为：

snowboard / working edge 在雪面上快速、重复跳动或震动，无法持续建立稳定 grip。

可能相关因素：

  • Pressure Management
  • rider rigidity
  • edge / pressure timing
  • balance over working edge
  • snow condition
  • equipment

因此 chatter 不应被简单处理成：

“Edge Angle 不够，再多立一点。”

是否以及哪一项为主要原因，需要实际观察。

Round Shape and Speed Control

turn-shape 已经建立：

Turn Shape 本身是 speed-control 工具。

Clean track 并不自动意味着高质量 Intermediate Carve。

如果 carved turns 很 open：

Long time travelling downhill
↓
Speed continues to build

因此还要关注：

  • roundness
  • completion
  • corridor
  • consistent speed

课程目标是：

clean + round + controlled

而不是只追求“没搓雪”。

Current Learning Level

本课用四层来区分 carving：

  1. Edge-to-edge — 能连续换刃
  2. Clean Carve — skid 明显减少，track 更 clean
  3. Round Carve — clean track + round shape + speed control
  4. Performance / Dynamic Carve — 更高 Edge Angle、更明显 loading / deformation / energy management

当前课程目标：

Intermediate Clean + Round Carve

Performance / Dynamic Carving 留待后续课程。

03如何观察或练习

观察 1：Track First

先看 snowboard track，而不是先看 rider 是否“压得低”。

观察：

  • track 是否细而 clean
  • Heel / Toe 是否一致
  • turn 前半段是否已经 skid
  • skid 是否只在 completion 才减少

观察 2：Transition / Edge Sequence

观察：

Old Edge Release
↓
Roll
↓
New Edge Engagement

是否流畅。

重点检查：

  • Pivot 是否抢在 new edge 前
  • old edge 是否 hold 太久
  • new edge 是否 late / abrupt

观察 3：Above the Fall Line

观察 turn 前半段：

  • new edge 是否已经开始有效建立
  • board 是否已经开始被 arc shape
  • 是否直到 fall line 以后才突然立刃

“Early”是 timing 概念，不代表最大 Edge Angle 必须提前出现。

观察 4：Heel-Side Body Organization

观察：

  • ankle contribution
  • knee contribution
  • hip angle
  • COM movement
  • whether hip folding appears too early
  • Range of Motion remaining at fall line / completion

观察 5：Chatter

如果出现 chatter：

不要先默认：

more edge

先观察：

  • Pressure
  • stiffness
  • timing
  • working-edge balance
  • snow surface
  • equipment condition

Carved Traverse

Purpose

先确认 rider 能否在单一 working edge 上形成 clean carved travel，而不是急着连接完整 turns。

Focus

  • stable edge
  • clean track
  • balanced position
  • minimal unnecessary steering

具体 CASI progression / terrain / 标准需来源核实。

Rail to Rail

Purpose

体验减少 unnecessary Pivot 后，单纯通过 edge change / sidecut 形成 direction change。

课程 mental model：

Toe Edge
↓
Release
↓
Flatter Board
↓
Heel Edge
↓
Sidecut Changes Path

Rail to Rail 只是 drill。

它不自动等于完整 Intermediate Carved Turns，因为还需要：

  • round shape
  • pressure
  • speed control
  • working-edge balance
  • turn completion

Edge Roll and Set

Purpose

强化 turn top / initiation 的 edge sequence。

观察：

  • Roll 是否 smooth
  • New edge 是否真正 establish
  • 是否在 edge set 之前加入过量 Pivot

具体官方 drill / progression wording 需来源核实。

04常见误区

误区 1：Carving = Edge Angle 越大越好

不对。

优先目标是：

  • clean track
  • round shape
  • balance
  • progressive edge / pressure
  • speed control

误区 2：身体越低 = carve 越好

不对。

低位如果来自 excessive hip folding，并提前耗尽 ROM，可能反而降低 adjustment ability。

误区 3：Pencil-like track = 高质量 Carve

不完整。

如果 turn 很 open、speed 持续增加，仍然缺少 round shape / speed control。

误区 4：Carving 完全不能出现任何 Pivot

本课训练目标是减少 unnecessary Pivot，并建立 clean carved outcome。

关于不同 carving task 中是否会出现少量 functional Pivot，应在后续更高阶课程和官方资料中继续区分，不能把当前训练目标扩大成所有场景的绝对规则。

误区 5：Chatter = Edge Angle 不够

不对。

Chatter 可能与 Pressure、rigidity、Timing、Balance、Snow / Equipment 等多个因素有关。

误区 6：Rail to Rail 就等于会 Carving

Rail to Rail 主要训练 edge-to-edge 与 remove pivot 感觉。

完整 Intermediate Carve 还需要 roundness、speed control、Pressure 与 Balance。

05助手解释

以下属于课程解释，不应视为 CASI 官方逐字原文：

  • “Sliding Turn 更多是把 board 转过去；Carving 更多是建立条件，让 snowboard 沿 edge / sidecut 走 arc。”
  • “Early Edge ≠ 一换刃马上最大 Edge Angle。”
  • “Pencil line 不等于 straight line。”
  • “Clean Track → Early Edge → Round Shape → Pressure / Balance → 再追求更高 Edge Angle。”
  • “Chatter 不是继续多立刃就一定能解决。”
  • “Rail to Rail 是 drill，不是最终完整 carving。”
06Personal Observation

用户目前：

  • Carving 处于入门阶段
  • Heel-side 曾描述“折下去以后，再继续压会感觉压不动”

本课建议后续通过视频 / 雪上验证：

Transition

  • old edge 是否 release cleanly
  • 是否 hold old edge / pressure too long

Pivot

  • 是否先 Pivot 再 Edge
  • turn initiation 是否出现明显 steering angle

New Edge

  • Heel-side edge engagement 是否 late
  • Heel / Toe edge timing 是否不对称

Heel-Side Position

  • 是否 early excessive hip folding
  • ankle / knee contribution 是否不足
  • 是否 very early 就进入 low / folded position

Range of Motion

  • fall line 前后是否已经接近 ROM limit
  • completion 是否还能继续 adjust / release

Track

  • Heel-side 是否前半 skid、后半才 clean
  • Heel / Toe track quality 是否明显不同

Chatter

  • 是否 Heel-side 更常出现
  • 是否在 speed / harder snow 增加时明显
  • 是否伴随 rider stiffness / late pressure

这些均未确认。

07Teaching English

Simple Explanation

A carved turn follows the edge of the snowboard with very little sideways skid.

Teaching Cues

Roll onto the new edge.

Set the edge early.

Let the sidecut shape the turn.

Avoid twisting the board into the turn.

Build the edge progressively.

Stay balanced over the working edge.

Keep the track clean.

Finish the turn to control your speed.

Observation Language

You're pivoting the board before the new edge is established.

The heel-side edge is engaging quite late.

The first half of the turn is still skidding.

You're using a lot of hip flexion very early.

The edge starts to chatter near the end of the turn.

Correction Language

Release the old edge more smoothly.

Roll onto the new edge before adding extra steering.

Let the edge build progressively.

Keep some movement available for the second half of the turn.

Focus on a clean, round track rather than getting lower.

10学习路径

建立 clean + round + controlled 的刻滑后，可继续 developing-carving，学习主动管理 roll / set、渐进屈伸、压力、弯形和释放。
