02核心解释

Edging

Edging 可以先理解为：

对 snowboard 与雪面之间 Edge Angle 的主动管理。

它不只是“把板立起来”。

真正需要管理的是：

  • 什么时候 release old edge
  • 什么时候 engage new edge
  • Edge Angle 建立到多少
  • Edge Angle 是否 progressive
  • rider 是否能够在 working edge 上保持 balance

Edge Angle

Edge Angle 可以理解为 snowboard base 与 snow surface 之间的夹角。

它是连续变量：

Flat
↓
Low Edge Angle
↓
Medium Edge Angle
↓
High Edge Angle

更高 Edge Angle 不自动意味着更好的 riding。它需要与 speed、terrain、turn radius、snow conditions 和 current task 匹配。

Working Edge

Working Edge 可以理解为：

当前主要承担支撑和控制任务的板刃。

例如：

  • Heel-side → Heel Edge
  • Toe-side → Toe Edge

本课把一个重要目标理解为：rider 不只是把 edge 放进雪里，而是要能在当前 working edge 上维持有效 balance。

Inclination

本课将 Inclination 解释为：

rider 的整体质量向 turn inside 移动。

它可以帮助 rider 在 turn 中建立 dynamic balance，并增加 Edge Angle。

学习时可以先记：

Move the mass inside.

Angulation

本课将 Angulation 解释为：

通过 ankles、knees、hips 等关节形成身体角度，从而进一步管理 Edge Angle，同时保持更有效的 balance relationship。

学习时可以先记：

Create joint angles.

Angulation 不应被简单理解成“折腰”或“把髋折得越深越好”。

Inclination 与 Angulation

本课采用以下教学性对照：

Inclination
= Whole-body lean / mass moves inside

Angulation
= Joint articulation / body angles

两者通常会组合使用。这是一种课程解释，不应视为 CASI 官方逐字定义。

Progressive Edging

本课强调 Edge Angle 应根据 turn progression 渐进建立。

Release old edge
↓
Transition
↓
Engage new edge
↓
Increase edge angle progressively
↓
Manage edge through the arc
↓
Release

实际滑行中这些阶段会重叠，不是机械的离散开关。

Edge Engagement

Edge Engagement 与 Edge Angle 不完全相同。

  • Edge Angle：snowboard 的几何立刃角度
  • Edge Engagement：working edge 实际开始与 snow 建立有效控制关系的时机与程度

因此可能出现 Edge Angle 已经很高，但 edge 仍然没有形成稳定 grip 的情况。

Edge Grip

Edge Grip 不是只由 Edge Angle 决定。本课把它理解为多因素共同作用的结果，包括：

  • Edge Angle
  • Pressure
  • Position & Balance
  • Speed
  • Snow Conditions
  • Timing & Coordination

所以：

High Edge Angle ≠ High Edge Grip

这是课程解释性总结，不是 CASI 官方原文。

Edge Platform

Edge Platform 可以先理解为：

working edge 与雪面建立稳定支撑关系后，rider 可以在其上维持 balance 的功能性支撑。

它不是一个真实存在的“平台”，而是帮助理解工作刃支撑关系的教学概念。

Edging and Pivot

Edging 与 Pivot 需要协调。

Lower Edge Angle
→ board easier to pivot / redirect

Higher Edge Angle
→ board more stable on working edge / more grip potential

真实滑行中两者会重叠，不是二选一。

Early Edge Engagement

Early Edge Engagement 可以先理解为：

在 transition 后较早开始建立 new working edge，而不是等到 turn 很晚才突然增加 Edge Angle。

Transition
↓
Old edge releases
↓
COM crosses
↓
New edge begins to engage
↓
Edge angle develops

后续 Carving 模块需要继续核实和展开。

03如何观察或练习

观察 1：Edge Angle 是否与 Task 匹配

不要只看“立得高不高”。应该结合当前速度、坡度、turn radius、snow conditions、是否需要 skid / carve，以及 rider 是否仍然稳定。

观察 2：Inclination 还是 Angulation

可以观察：

  • rider 是否只是整体像一根杆一样向弯内倒
  • ankle / knee / hip 是否真正参与
  • 是否通过大量 hip folding 代替更协调的 joint movement
  • 增加 body angle 后，board 是否真的获得更有效的 edge response

观察 3：Working Edge 上是否稳定

关注：

  • edge 是否突然丢 grip
  • 是否需要 upper body compensation
  • rider 是否还能继续调整
  • Edge Angle 增加以后 Balance 是否仍可控

Static Edging — Inclination vs Angulation

Purpose：区分 whole-body inclination 与 joint-based angulation。

Focus：观察不同身体组织下 COM、Edge Angle 与 balance余量如何变化。

具体官方 drill 标准需要后续核实。

Rail to Rail / Sidecut Turns

Purpose：减少不必要 Pivot，体验 edge-to-edge transition 与 sidecut response。

Focus：release old edge、pass through flatter board、engage new edge，并尽量减少多余 steering。

具体官方 drill 标准需要后续核实。

Progressive Edge Build

Purpose：避免突然强行达到高 Edge Angle。

Focus：让 Edge Angle 随 turn progression 逐步建立。

04常见误区

误区 1：Edge Angle 越高越高级

高 Edge Angle 如果与 speed、terrain、pressure、balance 不匹配，可能导致 edge loss 或动作被锁死。

更好的判断是：当前 Edge Angle 是否帮助 snowboard 完成 task？

误区 2：Angulation 就是折腰

如果 rider 主要靠 excessive hip flexion，而 ankle / knee contribution 很少、COM relationship 不理想、board edge response 没有明显改善，那么“身体折得很深”并不等于高质量 Angulation。

误区 3：Carving 就是身体越低越好

本课不把“摸雪”“身体很低”视为输入目标。更重要的是 Edge Angle、Edge Engagement、Working-edge balance、Pressure、Timing 和 Board Performance。

误区 4：有 Edge Angle 就一定有 Grip

Edge Grip 还受 Pressure、Position、Speed、Snow Conditions、Timing 等影响。

误区 5：Toe-side / Heel-side 必须有固定唯一姿势

本课没有给出固定关节角度或唯一标准外形。身体组织必须根据当前 task 与条件调整。

05助手解释

以下是本课用于理解的教学性表达，不应视为 CASI 官方原文：

  • “Inclination 负责进去，Angulation 负责精调。”
  • “Angulation ≠ 折腰。”
  • “High Edge Angle ≠ High Edge Grip。”
  • “Carving 的目标不是身体越低，而是 board performance。”
  • “Lower Edge Angle 更容易 Pivot；Higher Edge Angle 更利于 Grip / Support。”
06Personal Observation

用户此前描述：

Heel-side Carving 中折叠下去以后，继续往前压会感觉‘压不动’。

本课增加了以下观察方向：

  • Angulation 是否主要变成 excessive hip folding
  • ankle / knee / hip 是否协调
  • 是否过早追求过高 Edge Angle
  • COM 是否与 working edge 建立有效支撑关系
  • 是否在 turn early phase 过早耗尽 Range of Motion

这些都没有通过视频或雪上训练确认，因此目前只能保留为待验证 hypothesis。

07Teaching English

Simple Explanation

Edging is how you control the angle between your snowboard and the snow.

Inclination

Inclination is leaning your whole body into the turn.

Angulation

Angulation is creating angles through your joints to increase edge angle while maintaining balance.

Teaching Cues

Release the old edge.

Engage the new edge.

Increase the edge angle gradually.

Move your body into the turn.

Use your ankles, knees and hips.

Stay balanced over the working edge.

Don't force the edge too quickly.
