转点与板头板尾位移

按章节展开阅读，保留完整的知识解释与资料边界。

01一句话回想

看雪板旋转时板头和板尾是否都参与位移，而不是只看后脚有没有“把板甩过去”。

02核心解释

第三课用 Centre Pivot Point 帮助观察雪板更接近围绕板中部旋转、nose 与 tail 都有位移的情况。这是理想化教学示意，不要求真实动作在几何上严格围绕板的正中心。

相对地，Rear-Foot Sweeping 可能表现为 front foot 附近较稳定、tail 横向扫动明显大于 nose。课后资料把它列为一个需要观察的转板问题，可能伴随更多横向滑移或较粗糙的转弯形状；具体滑手是否存在该问题，仍需视频或雪上观察。

03如何观察或练习

看板头和板尾相对于雪面的轨迹，记录哪一端移动更多，再结合 steering-angle 和当前任务判断。课后资料提到 X-Turns 可用于观察 nose / tail 是否都参与转向；练习的官方执行标准仍待核实。

04相关知识
  • pivot：完整课程笔记与转板观察框架。
  • lower-body-steering：检查身体如何发起和引导板的旋转。
  • steering-angle：检查板朝向与行进方向的角度差。
