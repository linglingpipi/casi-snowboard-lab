01CASI Framing

基于当前项目已审计的 CASI Level 3 Riding Module Course Guide：

  • Printed p.6 / Free Run (Un-groomed Terrain)：要求在非机压、起伏地形展示 advanced-level control，选择 efficient line，保持 relatively consistent turn corridor。
  • Printed p.7 / Assessment Criteria：要求 effective lines、relatively consistent corridor，结合 terrain / snow 调整 body position 与 movements，并有 refined pressure regulation / steering。

Official PDF：https://members.casi-acms.com/documents/RidingModule_LEVEL%203%20COURSE%20GUIDE-EN.pdf

当前证据未定义唯一 Mogul Line、包顶换刃规则或最佳固定节奏。下述线路家族是本站课程分析模型。

02Line and Timing Work Together

本课的关键不是单独把转弯动作做得更激烈，而是理解：

Terrain / Snow / Space
→ Line Choice
→ Where and how the board meets features
→ Loading / contact / steering opportunities
→ Pressure / Steering Timing
→ Board Outcome and next-line options

这是 qualitative decision model，非 CASI 固定算法或物理公式。Line 与动作相互影响，不能宣称路线单独决定所有压力结果。

03Course Line Families

Round / Around

绕过一些凸起，利用较完整弧线或横坡运动安排速度控制。

可能的优势：在适宜坡度、雪况及空间下，为渐进 steering / pressure regulation 保留更多时间；适合初期的 line planning。

局限：需要足够侧向空间；硬雪包肩/人流/狭窄走廊可能使“绕包”并不容易。不是所有地形的最安全线路。

Crest / Shoulder-Oriented

利用某些雪包的肩部 / 顶部附近组织 release 与 direction change。结合后续的腿部活动和 unloading，可能获得更易 redirect 的机会。

局限：高点未必低压；雪包可能不规则、顶部硬或伴随失去 snow contact 的风险。不是每一弯都必须 crest edge change。

More Direct / Trough-Oriented

较多沿 fall line 或包槽走向滑行。在坡度与雪况相近时，可能加快速度累积、增加地形冲击，缩短可用于调整的时间。

局限：Direct 不是 advanced 的同义词；如果出现 panic brake / corridor loss 就与 Free Run desired outcome 不符。

真实路线可自由混合，不要求完整 run 固定某一种“线路风格”。

04Shape, Speed and Corridor

与 turn-shape 的关系：

  • More round / completed path 在某些坡度和条件下可帮助分配方向变化与速度管理任务。
  • More open / direct path 在其他条件相近时可能容许更快 downhill travel，随后提高 steering / control demand。
  • Corridor 是 rider 路径组织与 line-planning quality 的 outcome，不等于每一个 turn radius 必须数学一致，也不是每一个 bump 必须配一弯。

课程总结：Speed management starts with line choice。这不是 CASI 逐字表述。

05Anticipation and Strength & Flow

与 strength-and-flow 的联系：

  • 观察 upcoming features，而不只盯住当前 bump。
  • 提前规划 2–3 个 feature 的方向与 exit。
  • 保持 body organized and mobile，避免每个包后完全 reset。

Near / Next / Exit 是课程视觉扫描框架，不是固定官方观察距离。

06Steering Versatility Application

steering-versatility 不要求每个 terrain 都做 high-edge carve。

Line、space、speed 和雪况变化时，滑手可以调整：

  • Controlled sliding / blend / carve 的 intended outcome；
  • Turn shape 和 size；
  • Pivot / Edge / Pressure 的组合。

Accidental skid 不自动代表 intentional blend；也不要因为路线看似直接就把高风险技法当成高水平。

07Movement Analysis

使用 advanced-movement-analysis 的 Outcome First 逻辑：

Task / Terrain / Snow
→ Intended Line & Target Speed
→ Observed Corridor / Speed / Board Path
→ Contact / Pressure / Steering clues
→ Movement hypotheses
→ One-variable tactic and re-observation

例如看到 rider 每包后突然横板：先记录 turn shape、进入路线与速度变化，再考虑晚减载、过直 line、缺乏 ROM、trailing-foot kick 等竞争性假设，不立即锁定单一原因。

08Training Ideas — Course Designed

Two Lines, Same Terrain

在可控小雪包、同一雪况 / 类似起始速度下比较较圆与包肩思路；记录 corridor、speed、pressure sensation、steering effort、continuity。避免多人场地中刻意占据多条横向路线。

Line First

先口头说出 upcoming two turns / features 的预期 line，再滑行，最后对比 plan 与 observed outcome。

Three-Feature Linking

在简单 terrain 提前看到下一两个 feature，避免每次只为通过眼前雪包而改向。

这些练习不是 CASI 的 Mandatory Free Run Progression。

09Teaching English

Plan your line two bumps ahead.

Choose a line that gives you time to steer.

Look beyond the next bump to your exit.

Manage your speed with the line and turn shape.
