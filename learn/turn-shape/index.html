02核心解释

Turn Shape 描述的是：

snowboard 在雪面上走出的 path 形状。

它是 riding outcome，不是某一个 body movement。

Fall Line

Fall Line 可以先理解为：

坡面上最直接向下的方向。

当 snowboard 更接近 fall line 时，通常更容易出现 speed build 的趋势。

因此 Fall Line 是分析：

  • turn 前半段
  • turn 后半段
  • speed
  • completion

的重要参照。

Above the Fall Line

可以先理解为：

新 turn 建立后、snowboard 尚未完全通过 fall line 的前半段。

Below the Fall Line

可以先理解为：

snowboard 通过 fall line 后，继续向 across the slope 发展的后半段。

这些描述用于建立空间理解，不应机械地当成固定时间比例。

Round Turn

Round Turn 可以先理解为：

direction change 更 progressive，snowboard path 更连续地从一个方向发展到 across the slope。

常见结果可能包括：

  • speed control 更平顺
  • pressure development 更连续
  • linked turns 更容易保持 flow

Open Turn

Open Turn 可以先理解为：

path 更直接向 downhill，turn completion 相对更少横过坡面。

Open 并不自动等于错误。

是否合适取决于：

  • speed goal
  • terrain
  • corridor
  • turn task

Turn Shape vs Turn Size

Turn Shape 与 Turn Size 不一样。

Turn Size 更接近：

  • short
  • medium
  • large

Turn Shape 更接近：

  • round
  • open
  • progressive
  • abrupt / Z-like path

两个 turn 可以 size 接近，但 shape 完全不同。

Shape Develops Through the Turn

Turn Shape 不是在某一个瞬间“做出来”的。

它是 turn-phases 中 direction change 持续发展的结果。

因此 shape 会受到：

  • Pivot
  • Edging
  • Pressure
  • Timing & Coordination

共同影响。

Turn Shape and Speed Control

课程的关键理解：

Speed Control 不只等于 braking。

如果 turn 更完整地发展到 across the slope，snowboard 的 travel direction 会更多离开 fall line，从而可以通过路线本身管理 speed。

课程 mental model：

Turn Shape
↓
Direction Control
↓
Speed Control

这是教学框架，不是完整物理模型。

Z-Shaped Path

本课用 “Z-shaped” 作为观察比喻：

  • 前半段较直
  • snowboard 在 fall line 附近停留较久
  • completion 突然大幅 redirect / brake

它不作为已核实的 CASI 官方错误分类。

03如何观察或练习

先看轨迹，不先看姿势

观察视频时先问：

  • turn 是 Round 还是 Open？
  • direction change 是 progressive 还是集中在弯尾？
  • snowboard 在 fall line 附近停留多久？
  • completion 是否真正完成 across the slope？

比较左右 Shape

比较 Heel-side 与 Toe-side：

  • size
  • duration
  • roundness
  • completion

如果一侧明显更开放，可能需要进一步检查五大 Skills。

用路线控制速度

在安全、适当的 terrain 中：

  • 不追求突然横板 brake
  • 尝试更连续地完成 turn shape
  • 观察 speed 是否通过 path 变得更可控

具体 drill 应由后续雪上课程根据 terrain 和 rider 状态设计。

04常见误区

误区 1：Speed Control 就是把板横过来刹

Turn Shape 本身也可以参与 speed management。

误区 2：Round 越圆越高级

Roundness 必须服务于当前 task。

有些任务需要更 open line。

误区 3：Turn Radius 就等于 Turn Shape

Radius / size 与 shape 是两个不同维度。

误区 4：只通过身体姿势判断 turn quality

Turn Shape 是 snowboard path outcome，应先观察 board path。
