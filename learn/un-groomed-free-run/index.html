DEEP DIVE / 详细知识

非机压雪自由滑

01CASI Framing

Printed p6：un-groomed / bumpy terrain、advanced-level control、efficient line、relatively consistent corridor。

Printed p7：Pressure regulation、Snow Contact through flexion/extension、effective lines、corridor、body-position / movement adaptation、refined pressure control / steering。

02Outcome-Based Task

官方支持的是：Control + Line + Corridor + Pressure Regulation + Snow Contact + Terrain Adaptation。 当前 source 不规定 one mandatory line / edge-change point / fixed movement sequence。

03Line and Corridor

连接 tactical-riding：line 会改变 speed build、terrain compression、steering demand、next-feature options。Relatively consistent corridor 是 observable outcome，不等于每弯 radius 完全相同。

04Terrain Adaptability Application

连接 terrain-adaptability：Free Run 不是在 bumps 中复制 groomer pose，而是根据 terrain / snow / line / speed 调整 movement。

05Advanced Competency Application

Strength & Flow：mobility、flow、look ahead / line planning。 Steering Versatility：根据 terrain / speed / line 调整 steering outcome，controlled slide / blend 可以是有效选择。

06Movement Analysis

TASK → LINE/CORRIDOR → BOARD OUTCOME → SNOW CONTACT → PRESSURE/STEERING → BODY MOVEMENT 这是课程分析 sequence。

07Source Boundary

Primary: CASI Level 3 Riding Module Course Guide, printed pp.6–7。 Official: task / line / corridor / Pressure / Snow Contact / terrain adaptation。 Course-only: diagnostic chain、video protocol。
