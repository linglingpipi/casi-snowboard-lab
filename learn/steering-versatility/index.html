01CASI Framing

CASI Level 3 Riding Module Course Guide 印刷页 7 将 Steering Versatility 列为四个 Advanced Riding Competencies 之一，并要求 Level 3 rider 对 Advanced Competencies 展示 consolidation。

同页 Short & Long Radius criteria 还要求 rider：

  • 根据 terrain / speed 调整 movement，产生 sliding 或 carved turns
  • 用 lower-body movements 引导 varied turn shapes / sizes
  • link momentum
  • control / redirect snowboard

印刷页 10 的 TECHNICAL PRESENTATION: ADVANCED COMPETENCIES 对 Steering Versatility 给出正式定义与 discussion points：

  • advanced riders 可以 blend movements，让 snowboard slide、carve，或产生两者之间的一系列结果
  • efficient steering movements 可以创造 varied turn shapes / sizes
  • 按 intended outcome 选择 edge、pivot、pressure 的合适 amount
  • increase / decrease Edge Angle 以改变 turn size / shape
  • 用 edge、pivot、pressure 管理 speed，包括 decrease / increase

本页没有给固定 blend 百分比或完整 drill progression。

02Core Model

课程 mental model：

Terrain / Speed / Space / Task
↓
Intended Outcome
↓
Pivot + Edge + Pressure
↓
Position supports
↓
Timing coordinates
↓
Board Performance
↓
Slide / Blend / Carve
03Advanced Riding ≠ Always Carving

高级 riding 的重点不是：

carve 越多越好。

而是：

snowboard outcome 是否符合 intended task。

因此 sliding 可以是高级、主动、合理的 outcome。

04Slide–Carve Continuum

课程模型：

More Slide
────────────
Blend
────────────
More Carve

这里只表示 outcome 是连续的，不表示存在官方百分比尺度。

05Intended Outcome

分析顺序：

  1. rider 想得到什么 outcome？
  2. actual snowboard outcome 是什么？
  3. actual 是否符合 intention？

例如：

Wanted Carve
↓
Late Edge
↓
Accidental Skid

这是 execution problem，不应自动称为 blend。

而：

Need More Speed Control
↓
Intentionally Add Steering
↓
Controlled Blend / Skid

才体现 Steering Versatility。

06Pivot

pivot 影响 snowboard orientation 与 steering amount。

通常 more Pivot 会增加快速 redirect / steering potential，但：

More Pivot ≠ automatically More Slide。

最终 outcome 仍受 Edge、Pressure、Timing 影响。

07Edging

edging 在本课不只是 grip control。

CASI page 10 明确把 Edge Angle 作为改变：

  • turn size
  • turn shape

的变量之一。

仍需保持：

More Edge ≠ Always Smaller Turn。

08Pressure

pressure 会影响：

  • grip
  • loading
  • snow contact
  • steering effectiveness
  • snowboard response

所以 Steering Versatility 不能只看 rotation / Pivot。

09Blend

Blend 是：

intentional + controlled 的 slide–carve intermediate outcome。

不把 accidental skid 包装成高阶 blend。

10Turn Size / Shape / Performance

Turn Size

  • short
  • medium
  • large

Turn Shape

  • round
  • open
  • progressive / abrupt

Board Performance

  • more sliding
  • blend
  • more carved

三个维度可以独立组合。

11Speed Management

CASI page 10 直接指出 edge / pivot / pressure 可用于 decrease 或 increase speed。

本站进一步把：

  • decrease
  • maintain
  • increase

都放进 speed management 框架；其中 maintain 是课程补充表达。

12Planned Skid

Sliding 可以是 planned outcome：

Terrain Ahead
↓
Need Smaller Corridor / More Speed Control
↓
Choose More Steering
↓
Controlled Skid

区别于：

Too Fast
↓
Panic
↓
Rear-foot Kick
↓
Braking Skid
13Break the Carve

developing-carving 中的 Break the Carve 可以作为本课的应用：

Cleaner Carve
↓
Increase Steering Component
↓
Blend
↓
More Controlled Skid

“tactical transition”属于本站课程整合解释，不是 CASI page 10 原句。

14Slide → Carve

Versatility 也是双向的：

Controlled Steering
↓
Direction Established
↓
Reduce Steering Component
↓
Increase Useful Edge Grip
↓
Cleaner Exit

这是课程应用模型，不是官方固定 sequence。

15Timing & Coordination

timing-and-coordination 决定：

  • Pivot 什么时候增加 / 减少
  • Edge 什么时候 release / build
  • Pressure 什么时候 manage / release
  • 三者如何 overlap

因此：

Same movement + different timing = different outcome.

16Short Radius Application

short-radius-sliding-turns 中 narrow corridor / short timing window 常需要 intentional controlled slide，而不是盲目追求 pure carve。

高级 Short Radius 更接近：

Quick Release
+
Efficient Steering
+
Appropriate Edge
+
Pressure Regulation

而不是：

Fast Rear-Foot Pivot
17Movement Analysis

观察任何 turn：

  1. Intended Outcome
  2. Actual Outcome
  3. Pivot
  4. Edge
  5. Pressure
  6. Timing
  7. Turn Shape / Size
  8. Speed outcome

这是本站分析框架，不是 CASI 固定八步表。

18Personal Observation

用户后续雪上 / 视频可验证：

Carving

  • intended carve 是否因 late edge 变 accidental skid？
  • Heel / Toe clean outcome 是否明显不一致？

Short Turns

  • black terrain 中 skid 是 intentional control 还是 panic brake？
  • steepening terrain 前是否会提前改变 steering strategy？

Outcome Control

同一缓坡能否主动做出：

  • cleaner carve
  • controlled slide
  • intermediate blend

Timing

  • carve → blend 是否 abrupt Pivot？
  • slide → cleaner finish 是否能渐进改变 steering component？

以上未确认。

19Training Ideas

Same Slope, Different Outcome

同一安全缓坡：

  • clean carve
  • controlled slide
  • blend

Same Turn Size, Different Performance

尽量保持类似 corridor：

  • Run A more sliding
  • Run B more carved

Carve → Blend

Clean Entry
↓
Carved Early Arc
↓
Gradually Add Steering
↓
Controlled Sliding Completion

Slide → Cleaner Finish

Controlled Steering Entry
↓
Establish Direction
↓
Reduce Steering Angle
↓
Increase Working-Edge Grip
↓
Cleaner Completion

以上是本站训练设计，不冒充官方逐步 drill。

20Teaching English

Choose the board performance you need.

Add a little more steering here.

Reduce the pivot and let the edge work more.

Blend the slide into the carve.

Use more edge to change the shape of the turn.

Manage your speed with edge, pivot and pressure.

Match the turn to the terrain.
