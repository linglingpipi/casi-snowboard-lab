DEEP DIVE / 详细知识

雪包基础

按章节展开阅读，保留完整的知识解释与资料边界。

01CASI Support

Printed p7 supports Pressure regulation、Snow Contact through flexion / extension、effective line、Position / movement adaptation、refined Pressure / Steering in mogul Free Run。

02Bump Anatomy — Course Language

Uphill Face / Crest / Downhill Face / Trough。非当前 Guide official anatomy classification。

03Terrain as Pressure Input

Course model：Rising terrain → board moves toward rider → Pressure tends to increase。Rigid body + terrain compression 可能形成 Pressure spike。非精确物理公式。

04Absorption / Retraction

Terrain rises → legs flex/retract → terrain input managed。 Absorption ≠ early squat。Pre-crouch 可能提前消耗 ROM。

05Extension

Terrain falls away → legs extend → Snow Contact can be better maintained。 只会 flex 而不会 re-extend，不是完整 terrain-following system。

06Centred & Mobile

Bumps 中 vertical ROM availability 很重要；lower body承担更多 terrain-following movement。Legs as suspension 只是 mental model。

07Snow Contact

Official criterion = maintain Snow Contact through flexion / extension。 课程边界：不是要求 board 100% 永远不离雪，而是 functional / controlled contact management。

08Steering Window — Course Term

定义：terrain / edge / loading state 下相对有利于 snowboard release / redirect 的机会窗口。 Crest / shoulder 附近可能提供 useful opportunity，但不意味着每弯必须 crest edge change。

09Edging in Bumps

Teaching Module printed p21 把 Flat-base against bumps 列为 Edging example tactic。它证明 flatter-board strategy 可以是 tactic，不等于 bumps 全程 flat-base。

10Line Families — Course Model

Round/Around；Crest/Shoulder-oriented；More Direct/Trough-oriented。不是 official three-line system。

11Down-Unweighting

down-unweighting 是 bumps 中可用的 specific tool；general absorption 与它不是同义词。

12Failure Hypotheses

Stiff Legs；Pre-Crouch；Missed Steering Window；One-Bump Vision；Brake Every Bump。均为课程 model。

13Source Boundary

Primary: Riding Module p7。 Supplementary: Teaching Module p21 (Flat-base against bumps, Reactive/Proactive, Down-Unweighting Progression, scanning)。 Course-only: anatomy、pressure models、Steering Window、line families、failure chains、suspension analogy。
