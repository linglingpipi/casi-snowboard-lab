02核心解释

Sliding Turn 可以先理解为：

snowboard 在改变方向的同时，存在一定程度的受控横向滑移 / skid。

在 Sliding Turn 中：

  • board longitudinal axis 与 exact direction of travel 可以存在差异
  • Pivot / steering 通常比 pure carved turn 更明显
  • Edge Angle、Pressure 与 Position 仍然决定 skid 是否可控

因此 Sliding Turn 不是：

只靠后脚把 board 扫出去。

Sliding Is a Valid Outcome

Sliding 不应被理解成：

“Carving 失败了。”

它是一种主动可选择的 snowboard outcome。

很多场景可能需要更多 slide / skid：

  • steep terrain
  • trees
  • bumps
  • narrow corridor
  • tactical speed control
  • short-radius steering tasks

高级 rider 的目标不是永远 carve，而是拥有：

根据 task 选择 slide、carve 或两者之间不同 blend 的能力。

这属于本课的核心课程理解；具体 CASI 官方 wording 仍待来源核实。

How Sliding Turns Work

Sliding Turn 仍然是五大 Riding Skills 的共同结果。

Position & Balance

rider 需要保持 centred & mobile，才能继续 redirect board、调节 edge 与 pressure。

Pivot

pivot 通常承担更明显的 board redirection / steering。

但 Pivot amount 应与 task 匹配。

Edging

edging 决定：

  • old edge release
  • new edge engagement
  • skid / grip 的 balance
  • working-edge control

Pressure

pressure 影响：

  • board loading
  • edge support
  • turn development
  • terrain adaptation

Timing & Coordination

timing-and-coordination 决定：

  • 什么时候 release
  • 什么时候 redirect
  • 什么时候 build new edge
  • 什么时候 manage pressure

因此 Sliding Turn 不是一个单动作技术。

Sliding Turn Across the Phases

Initiation

课程分析框架：

Release old edge
↓
Board becomes easier to redirect
↓
Body moves toward new turn
↓
Begin steering as needed

Execution

Board continues redirecting
+
New edge develops
+
Pressure develops / is managed
+
Turn shape becomes clearer

Completion

Continue steering as needed
↓
Bring snowboard more across the slope
↓
Manage speed and forces
↓
Prepare release into next turn

这是学习框架，不是固定动作处方。

Turn Shape and Speed Control

Sliding Turn 的质量不能只看：

skid 有多少。

还要看：

  • Turn Shape 是否符合 task
  • speed 是否可控
  • movements 是否 progressive
  • skid 是否 predictable
  • linked turns 是否流畅

turn-shape 可以帮助 rider 用 path 管理 speed，而不是每一弯都依赖 abrupt braking。

Beginner / Novice Context

本课提到 QuickRide 中：

  • Beginner Turns 更关注 edge-to-edge turning 的建立
  • 后续 Flow 阶段会把 linked turns、flexion / extension、speed control 等进一步组合

但本课包没有保留 QuickRide 官方段落，因此这一部分仅保留为课程上下文，具体 wording 需核实。

03如何观察或练习

观察 Board Orientation 与 Travel Direction

从俯视视频或轨迹观察：

  • board 是否发生 controlled skid
  • steering 是否 progressive
  • 是否 sudden rear-foot sweep
  • skid amount 是否与 task 匹配

观察 Turn Shape

先看：

  • Round / Open
  • completion
  • speed control
  • linked flow

再判断是哪一个 Riding Skill 导致 outcome。

观察是否只靠弯尾 Brake

典型待检查 pattern：

Open initiation
↓
Speed builds
↓
Late large pivot
↓
Abrupt skid / braking

如果出现，需要进一步分析：

  • timing
  • pivot
  • edging
  • position
  • pressure

而不是只说“搓雪太多”。

04常见误区

误区 1：Sliding = 错误

不对。Sliding 可以是有意选择的 outcome。

误区 2：会 Carving 以后就不需要 Sliding

不对。不同 terrain 和 tactics 仍然需要 steering versatility。

误区 3：Sliding Turn 就是后脚扫板

高质量 Sliding Turn 需要五大 Riding Skills 协调。

误区 4：Skid 越少越好

Skid amount 应根据 task 调整，而不是一律最小化。

误区 5：只要能控速就是好 Sliding Turn

还要看：

  • turn shape
  • symmetry
  • timing
  • balance
  • predictability
  • flow
05Teaching English

Simple Explanation

A sliding turn changes direction while the snowboard is also skidding across the snow.

Teaching Cues

Let the board come around progressively.

Finish the turn more across the slope.

Keep the skid controlled.

Don't kick the back foot out.

Release the old edge smoothly.

Keep the turns round and consistent.

Observation Language

Most of the skid happens at the end of the turn.

You're pushing the tail out quite suddenly.

The turn is staying very open above the fall line.

Correction Language

Start shaping the turn earlier.

Let the board steer more progressively.

Finish the turn a little more across the slope.
