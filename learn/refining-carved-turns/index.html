01导读

本篇为第 12 课的课后学习整理。以下技术模型、drills、tactics 与英文提示均为课程解释，尚未核对 CASI 官方 Guide 原文、版本及页码，不作为已确认的 CASI official framing。Personal Observation 是个人体验；所有 Heel-side 成因分析均为 hypothesis，待视频 / 雪上验证。英文 Observation Language 为示例句，不代表已观察到用户存在该问题。

02核心解释

Refining Carved Turns 是在 clean / developing carved outcome 基础上，扩大 rider 的 control range。

本课问题从：

Can I control the carve?

进一步变成：

Can I stay balanced, mobile and adaptable while carving?

目标：

Working-Edge Balance
+
Mobility
+
Symmetry
+
Quickness
+
Adaptability

真正追求的不是：

More Edge

而是：

More Control Range。

03Working-Edge Balance

edging 中已经建立 Working Edge 的概念。

本课把 Working-Edge Balance 理解为：

snowboard 已经建立 working edge 后，rider 仍能随着 forces、speed 与 turn progression 持续调整 Position、Pressure 与 movement，同时维持有效 edge relationship。

课程 mental model：

Working Edge Engaged
↓
Forces Change
↓
Rider Adjusts
↓
Effective Edge Relationship Remains

因此：

stable ≠ locked。

04Stable but Mobile

错误理解：

Carve
↓
Find strong position
↓
Freeze

更好的理解：

Carve
↓
Find effective support
↓
Keep adjusting as forces change

Carving 中的稳定应当是：

dynamic stability。

centred-and-mobile 在本课重新成为核心。

05Dynamic Inclination and Angulation

edging 中已有：

  • Inclination
  • Angulation

本课不再只把它们当定义，而是作为 turn progression 中不断调整的变量。

Early Turn

  • move into new turn
  • establish edge relationship

Mid Turn

  • forces develop
  • body angles continue adjusting

Late Turn

  • manage pressure
  • preserve mobility
  • prepare release

重点：

body angles should remain adaptable through the arc。

06Release and Build

很多 rider 很会：

build edge / pressure。

但不擅长：

release。

本课建立：

RELEASE
↓
ROLL
↓
SET
↓
BUILD
↓
MANAGE
↓
RELEASE

Good carve 不只是 build cycle。

Release 同样是主动 control skill。

Release Is Not “Doing Nothing”

Edge / Pressure release 可能帮助：

  • board become easier to transition
  • reduce old-edge dependence
  • create space for next turn
  • enable quick edge change

具体 movement strategy 会随 task 改变。

07Hopping in Traverse

本课把 Hopping in Traverse 作为一个 refinement drill 理解。

Purpose

放大：

  • centred position
  • pressure release
  • working-edge balance
  • mobility

如果 rider 主要依赖：

  • rigid body
  • highback
  • fixed edge support

可能更难完成小 hop 并重新稳定回到 edge。

它不是：

jumping skill test。

具体 CASI drill 标准需来源核实。

08Heel-Side Highback Dependence

Heel-side 中可能出现：

Calves press hard into highback
↓
Hips drop back
↓
Body hangs behind board
↓
Heel edge engages
↓
Movement options decrease

这是观察 hypothesis，不是用户已确认问题。

Highback 本身是正常 equipment support。

问题是：

是否过度依赖它，以至于身体失去 mobility。

09No High-backs Analogy

本课只把该名称作为 coaching analogy 保留。

课程理解：

Heel-side 不要只是向 highback 上“躺”，而应通过 ankle / knee / hip organization 与 active balance 维持 working edge。

它不意味着真正拆掉 highback。

官方内容需来源核实。

10Rail to Rail — Refining Focus

Rail to Rail 在不同阶段 focus 不同。

Beginner Carving

  • remove unnecessary Pivot
  • understand edge-to-edge

Refining Carving

  • improve smooth release
  • edge-change timing
  • Heel / Toe symmetry
  • quickness
  • track quality
  • upper-body stability

因此：

same drill, different focus。

11Quickness

timing-and-coordination 已经建立：

Quickness 不等于 abrupt movement。

在 Refining Carving 中，Quickness 更接近：

快速、准确、平顺地改变 edge relationship。

因此：

Fast
+
Smooth

可以同时成立。

12Hop to Change Edges

本课把 Hop to Change Edges 作为 drill mental model：

Loaded Working Edge
↓
Pressure Release
↓
Board Becomes Light
↓
Edge Change
↓
New Working Edge

它不表示真实 carving 必须跳起来换刃。

主要用于放大：

  • release
  • timing
  • centred position
  • edge independence
13Traverses with Flexion

课程 mental model：

Stable Working Edge
↓
Slow Flexion
↓
Maintain Track
↓
Extend / Reorganize

Purpose：

在减少 turn complexity 的情况下，检查 rider 改变 body height 时能否保持 working-edge relationship。

coordinated-flexion 在这里非常重要。

如果 Flexion 变成：

Hip Collapse
↓
COM relationship deteriorates
↓
Board skids

说明 movement organization 值得进一步分析。

14Slow Vertical Movement

课程 mental model：

Higher
↓
Slow Flexion
↓
Lower
↓
Slow Extension
↓
Higher

同时尽量保持：

clean edge track。

用途之一：

分离 Body Movement 与 Board Outcome。

因此：

Body Movement
≠
Automatic Board Outcome

真实 outcome 仍由：

  • movement timing
  • force
  • Edge
  • Position
  • Pressure
  • Speed

共同决定。

15Edging + Pressure + Position + Timing

Refining Carving 进一步强化：

Good Carving
≠
Edging Only

Working-edge performance 更接近：

Edging
+
Pressure
+
Position
+
Timing

pressure 不应被简化为主动往下踩。

16Chatter

Chatter 仍作为多变量 symptom 分析：

Chatter
↓
Check Position
↓
Check Edge Timing
↓
Check Pressure
↓
Check Rigidity
↓
Check Snow / Equipment

不能使用：

Chatter = Edge Angle 不够

这种单变量诊断。

17Cowboy Knees

本课只保留 Cowboy Knees 作为 coaching tactic 名称。

课程理解：

  • promote active lower body
  • use knees / hips
  • increase articulation
  • avoid locked legs

不把它当成固定标准动作。

官方 tactic 内容需核实。

18Drinks on Shoulders

本课把 Drinks on Shoulders 作为 upper-body control analogy 理解。

目的：

  • reduce unnecessary upper-body movement
  • improve stability
  • allow lower body to work more independently

它不代表：

  • shoulders 永远水平
  • upper body 完全冻结

因此：

quiet ≠ frozen。

19Symmetry

Refining Carving 中 Heel / Toe symmetry 可以比较：

  • turn duration
  • edge engagement timing
  • edge-angle progression
  • pressure progression
  • release timing
  • remaining ROM

不要求身体外观完全镜像。

Counting for Symmetry / Quickness

Counting 可以作为 observation / drill tool：

Toe:
1 — 2 — 3

Heel:
1 — 2 — 3

用于比较：

  • cadence
  • duration
  • edge timing
  • quickness
  • symmetry

具体 CASI drill wording 需来源核实。

20Adaptability

Refining Carving 不只是 repeatability。

Repeatability

相同条件下重复同样的 carve。

Adaptability

radius、line、speed、terrain 或 pitch 变化后，仍能调整 movement 并保持有效 carved outcome。

课程 mental model：

See
↓
Anticipate
↓
Adjust
↓
Maintain Carve

timing-and-coordination 中 Anticipation / Adaptability 在这里重新应用。

21Follow the Leader

Follow the Leader 可以用于制造：

  • radius changes
  • line changes
  • speed changes
  • rhythm changes

让 rider 必须调整：

  • Timing
  • Edge
  • Pressure
  • Position

因此它更像：

adaptability challenge。

具体 CASI tactic 需来源核实。

22如何观察或练习

观察 1：Working-Edge Mobility

观察 rider carve 时：

  • lower body 是否还能 move
  • joints 是否 locked
  • forces 增加后是否还能调整

观察 2：Release

看：

  • old edge 是否 hold too long
  • pressure 是否 release
  • next edge change 是否 quick but smooth

观察 3：Heel-Side Highback

看：

  • calf / highback contact
  • hips 是否过度后掉
  • rider 是否只能靠 highback 支撑
  • highback support 增加时 mobility 是否下降

观察 4：Traverse + Flexion

看 body height 改变时：

  • track 是否保持 clean
  • ankle / knee / hip 是否 coordinated
  • 是否 hip collapse

观察 5：Heel / Toe Symmetry

比较：

  • duration
  • edge timing
  • pressure timing
  • release
  • remaining ROM

观察 6：Adaptability

稍微改变：

  • radius
  • line
  • rhythm
  • pitch

看 carved outcome 是否仍然：

  • clean
  • round
  • controlled
23常见误区

误区 1：Refining = More Edge

不对。

Refining 更重要的是：

More Control Range。

误区 2：稳定 = 身体不动

不对。

Working-edge balance 是 dynamic balance。

误区 3：Heel-side 就应该一直压 highback

Highback 是正常 equipment support，但过度依赖可能限制 mobility。

误区 4：Release 是自然发生，不需要控制

不对。

Release 是 carving cycle 的重要部分。

误区 5：Flexion 越大越高级

不对。

重点是 coordinated、task-specific，并保持 working-edge relationship。

误区 6：Quiet Upper Body = Frozen Upper Body

不对。

Quiet 代表减少无效 movement，不代表失去 adjustment capacity。

24助手解释

以下属于课程解释，不应视为 CASI 官方逐字原文：

  • “More Control Range，而不是 More Edge。”
  • “你是在 edge 上平衡，还是靠固定结构挂在那里？”
  • “Fast + Smooth 可以同时成立。”
  • “Release 与 Build 同样重要。”
  • “Good Carving ≠ Edging Only。”
  • “Quiet ≠ Frozen。”
  • “Repeatability ≠ Adaptability。”
25Personal Observation

用户此前 Heel-side 有：

折下去以后继续压会感觉‘压不动’。

本课新增待验证 hypothesis：

Highback Dependence

  • 是否过度依赖 highback
  • 是否形成 stable but not mobile 的 Heel-side position

Coordinated Flexion

  • ankle / knee / hip 是否共同参与
  • 是否 Flexion 变成 hip collapse

Release

  • edge 建立后是否 hold 太久
  • 是否缺少主动 release

Symmetry

  • Heel / Toe duration
  • edge timing
  • pressure timing
  • remaining ROM
  • release timing

Chatter

  • 是否与 rigidity / higher speed / harder snow / late pressure 有明显相关

以上全部未确认。

26Teaching English

Simple Explanation

Refining carving means staying balanced, mobile and adaptable while the snowboard is working on edge.

Teaching Cues

Stay balanced over the working edge.

Stay mobile while the board is carving.

Don't just lean against the highback.

Use your ankles, knees and hips together.

Release the edge smoothly.

Keep the upper body quiet.

Try to make both turns the same duration.

Adapt the movement, not just the line.

Observation Language

You're stable, but you're getting quite locked.

You're relying heavily on the highback on your heel-side.

The old edge is releasing quite late.

Your heel-side takes longer than your toe-side.

Correction Language

Stay mobile instead of holding one position.

Use the highback as support, not as the whole balance strategy.

Release the old edge more smoothly.

Keep the lower body active while the upper body stays quieter.
